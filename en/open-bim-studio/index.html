Open BIM Studio

From first layout to reinforcement and drawings, in one open BIM model

Set out levels, grids, walls and floors, then develop the same model with reinforcement, connections, sections and sheets. Everything stays in IFCX, the open OpenAEC format.

Features

Model, reinforce and draw in one model

Start with the highlights, or pick a topic.

01 Modelling

Set out a building the way you sketch

Levels, grids, layered walls, floors, roofs, columns, beams and piles sit in one ribbon. Grab a grip, snap to the grid and push or pull a face to the right size.

Learn more

02 Reinforcement

Reinforcement that follows the concrete

Place bars, stirrup cages, meshes and area reinforcement parametrically in beams, columns and slabs. Position labels with diameter and spacing appear on the drawing in Dutch or international notation.

Learn more

03 3D and section box

Look straight through the model

Cut the model open with a section box and orbit it with the view cube. The wireframe shows the reinforcement in slabs, columns and pad foundations; shadows, colour and hidden lines switch on or off with one click.

Learn more

04 Drawings

Sheets that move with the model

Plans, sections and elevations come straight from the model, with dimensions, tags and drawing standards. Place them on a sheet with a title block and export to PDF or SVG.

Learn more

  • Levels and grids

    Work per level with PgUp and PgDn, and repeat grid lines with a pattern such as 5000 3x5400.

  • Walls, floors and roofs

    Layered walls, floors, roofs, ceilings, skirtings and spaces.

  • Columns, beams and piles

    Structural members in concrete or steel, with a library of European steel sections.

  • Windows, doors and window systems

    Openings, Dutch doors and your own types, and window systems hosted in the wall.

  • Push, pull and snap

    Grips, numeric input, snapping to end, mid and intersection points, Push/Pull and face splitting.

  • Parametric building systems

    System types with frames and panels, stairs, railings and component libraries.

  • Bars, cages and meshes

    Straight, L and U bars, stirrup cages, meshes and area reinforcement, parametric in the host.

  • Positions and notation

    Position labels with count, diameter and spacing, in Dutch or international notation.

  • Light display in 3D

    Reinforcement as centre lines for a smooth view; switch on the real diameter when you need it.

  • Steel connections

    Parametric joints with plates, bolts, welds and member cuts, as reusable types.

  • Plans and sections

    Views with their own scale, cut height, hatching and drawing type, straight from the model.

  • Sheets to PDF and SVG

    Place views on a sheet with paper size, title block and legend, and output it as PDF or SVG.

  • Schedules and quantities

    Schedules of walls, windows and doors, floors, spaces and reinforcement, with length, area and volume, exportable as CSV.

  • 3D with section box

    Shaded, hidden line or wireframe, with shadows, a view cube and a section box you move with grips.

  • IFCX as the project file

    Your work is stored as compact binary IFCX (.ifcxb) or JSON IFCX, readable by the other OpenAEC apps.

  • IFC in and out

    Import and export IFC; supported elements become editable objects, the rest stays as reference.

  • DXF as underlay

    Read a DXF drawing as reference geometry to model over.

  • AI assistant via MCP

    A local API and an MCP adapter let scripts and AI assistants create walls, floors and grids and change properties.

  • Model explorer

    Levels, grids, types and views in a tree, with the properties alongside.

  • Undo and redo

    Every edit is one step you can undo or redo.

Frequently asked questions

Which files can I open?

Projects in binary IFCX (.ifcxb) or JSON IFCX (.ifcx), IFC files from other BIM software and DXF drawings as underlay. Not every imported IFC object becomes fully editable; keep your source files.

Do I need to install anything?

Yes. There is no web version. Download the Linux installer (.run) and start it with bash; it installs per user in your home folder and adds the app to the menu.

What does it cost?

Nothing. Open BIM Studio is open source under the MPL-2.0 licence, with no account or subscription.

In which file format is my work saved?

In IFCX, the open OpenAEC format: compact binary as .ifcxb or as JSON (.ifcx). You can also export to IFC, drawings to PDF or SVG and schedules to CSV. The format is still evolving; work on copies.

Which systems does it run on?

On Linux x86-64 with glibc 2.38 or newer, an X11 session (or XWayland) and a graphics card with Vulkan. A tested Windows installer is not available yet; macOS not yet either.

Does it fit building practice?

It works with levels, grids, IFC and Dutch reinforcement notation, and has European steel sections. It is a preview: there is no IFC certification and no check against building codes.

What can an AI assistant do with it?

Through the MCP adapter or the local API, an assistant creates walls, floors, grids and building systems, selects elements, changes properties and types, and undoes steps.

Can I use it for a real project yet?

Not yet. It is a development preview: not every combination of features is finished or tested, and performance on large models is still being improved. Try it with the example building and report what you find.

What is DynLex?

The programming language the modeller is written in, developed within OpenAEC. The code reads almost like English and is compiled to fast native code via LLVM.

What language is the interface in?

In English for now. Country-specific content, such as Dutch reinforcement notation, is chosen per project.

Technology

For those who want to know how it is built.

DynLex

The BIM logic, tools and geometry are written in DynLex and compiled to native code via LLVM.

Own CAD kernel

Planar geometry, NURBS and B-rep in its own kernel; the model keeps the objects, a separate layer derives the geometry.

Vulkan and GLFW

A native interface that talks to the graphics card directly, with no browser or runtime in between.

IFCX

The open data format of the OpenAEC ecosystem, binary (.ifcxb) or JSON, alongside IFC for exchange.

MCP

A stdio MCP server and a local HTTP API drive the editor; every model edit is one undo step.

MPL-2.0

The app source code is under MPL-2.0; the DynLex runtime under LGPL-3.0. Releases come with SHA256 sums and a signature.
