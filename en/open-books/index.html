Historical building literature

OpenBooks

Trade books nobody prints any more, free to open in your browser

Anyone renovating or assessing an existing building wants to know how it was built back then. OpenBooks puts scanned building books from 1670 to the 1960s online: pick a book, leaf through the original pages and zoom into the drawings.

Frequently asked questions

Which books are included?

The reader holds twelve books with over 2,300 pages in total: five volumes of Wattjes' Constructies van Gebouwen, Gugel's Architectonische Vormenleer, Vandepitte's Berekening van Constructies I, Staalconstructies by Potma and De Vries, Zwiers' Handboek Houtconstructies, the 1950 reinforced concrete code, Bosboom's Cort onderwys from 1670 and a book on panel doors. GitHub holds even more scans, such as the other volumes of Wattjes and Vandepitte, Bernoulli's Vademecum and the 1974 concrete code.

Do I need to install anything?

No. Open open-books.open-aec.com in your browser and pick a book. No account needed.

What does it cost?

Nothing. OpenBooks is free and open source; the website and scripts are licensed under the LGPL-3.0.

What file format are the scans in?

Every page is a separate image (PNG or JPG) in one folder per book on GitHub. You can view and download them there, page by page or as the whole collection.

Which systems does it run on?

In any modern browser on Windows, macOS and Linux. It works best on a computer with a mouse; the site itself is in Dutch.

Does it fit building practice?

Yes, for work on existing buildings: you see how walls, foundations, frames, stairs and roofs used to be built and calculated. Note: the codes in the collection are historical and no longer apply today.

Can I search the text of the books?

Not yet. The search box currently searches by title and author. Text recognition (OCR), so you can search for words in the pages and copy text, is planned.

Are these books allowed online?

As far as can be traced, the books are free of rights. That is sometimes hard to establish. If you think a book is still under copyright, report it on GitHub and we will remove it.

Can I add a book?

Please do. Scan a rights-free building book and submit the pages as a contribution on GitHub, or open an issue with a tip for a book that belongs here.

Technology

For those who want to know how it is built.

React 18

The library and the reader are a single web page built with React, without a build step.

Git

All scans live in a Git repository, one folder per book, so every change can be traced.

Static site

No server code or database: the pages load straight from the repository.

GitHub Actions

A workflow automatically publishes every change to open-books.open-aec.com.

Python

Small scripts number and rename the scanned pages per book.

LGPL-3.0

Open licence for the code; the books themselves are, as far as can be traced, free of rights.
