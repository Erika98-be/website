Open Pile Plan Studio

From loads and CPTs to a well-founded pile plan

Import the load points, CPTs and foundation advice and see for each location which pile fits, what it costs and how heavily it is loaded. Assign choices, let the app find the cheapest coherent variant and export the plan to Excel.

Features

Everything for the pile plan, on one drawing

Start with the highlights, or pick a topic.

01 CPTs

See which CPTs govern a pile

For each load point the app selects the CPTs per quadrant or within a maximum angle, with the distance and bearing capacity alongside. Lines on the drawing show which CPTs count; override the choice when you want something else.

Learn more

02 Optimisation

Let the app find the cheapest coherent plan

The optimiser looks for the lowest cost within your limits on the number of pile sizes and tip levels. It then makes the plan calmer: fewer differences between neighbours, within a small cost budget. You can see whether the result is proven optimal.

Learn more

03 Pile caps

Try more piles under one cap

Set a pile-cap proposal of 1 to 20 piles for a location or group and immediately see which pile options fit and what they cost. The proposal is stored with the pile plan; an overview lists all changes in the plan.

Learn more

04 Export

A pile schedule the way you want it

Choose which pile plan to export, which columns it contains, in what order and what they are called. You see the table straight away in a preview and save it as Excel or CSV. A change table compares it with an earlier version.

Learn more

05 Input

Your own tables as the starting point

Import load points, CPTs and foundation advice from CSV or Excel, also directly from an RFEM export. Each source is kept as a table in the project. When the structural model changes, refresh the source: linked choices move to the new locations.

Learn more

  • Pile options per location

    For each location every combination of pile size and tip level: valid, insufficient or without advice, with the governing CPT.

  • Utilisation and cost

    Compare utilisation, bearing capacity and estimated cost before you choose a pile. Sort and filter every column.

  • One choice for many locations

    Select by clicking, with Shift or with a lasso; the table then shows the options that apply to all locations.

  • Groups

    Bundle locations into a group with the same pile. Groups with conflicting choices turn red.

  • Pile-cap proposals

    Try 1 to 20 piles under a cap, with indicative options and costs. Resetting everything takes one step.

  • Lock choices

    Lock fixed choices per pile plan; the optimiser then leaves them as they are.

  • Legend and display

    Filter by pile size and tip level, adjust symbols and colours and choose which columns you see.

  • Select CPTs automatically

    Per quadrant or within a maximum angle, with a distance limit.

  • Override manually

    Change the CPTs for one location or a whole selection at once, and restore the automatic choice whenever you like.

  • Combine foundation advice

    Several advice files and worksheets in one project, also as a table with one column per pile size. Conflicting values are reported.

  • Lowest cost

    The optimiser finds the cheapest assignment within limits on the number of pile sizes, tip levels and configurations.

  • A calmer plan

    Fewer differences in tip level and pile size between neighbours, within a cost budget (5% extra by default).

  • Quick improve

    A quick local improvement as an alternative to the full calculation. You always see whether a result is proven optimal.

  • Several pile plans

    Keep variants side by side in one project, with the total cost per plan.

  • CSV, Excel and RFEM

    Give each file a role before importing. An RFEM export is recognised; you first see a preview with any errors.

  • Refresh sources

    New loads from the structural model? Link old and new locations on a large drawing; choices and locks move along.

  • Import an existing pile plan

    An Excel or CSV table becomes a new pile plan, matched by ID or coordinate, with a check beforehand.

  • Pile schedule to Excel or CSV

    Your own columns, order and headers, pile numbering and units, with a live preview.

  • Change table

    Compare with an earlier pile schedule: moved, other size, other level, added or removed, with codes you choose yourself.

  • Everything in one project file

    Sources, settings, choices and variants in one IFCPP file, with undo and recovery after a browser crash.

  • AI assistant (Windows)

    Connect ChatGPT Desktop or Claude Desktop to the open project. Reading and editing are switched on separately.

Frequently asked questions

Which files can I open?

Load points, CPTs and foundation advice as CSV or Excel (XLSX), loads also as an Excel export from RFEM. Also projects in IFCPP and existing pile schedules from Excel or CSV.

Do I need to install anything?

No. The web version opens straight away with a sample project. You only need the Windows app for the AI assistant connection and to open IFCPP files from Explorer.

What does it cost?

Nothing. Open Pile Plan Studio is free and open source under the LGPL-3.0 licence, without an account.

In which file format is my work saved?

In an IFCPP file: an open, readable project format with all sources, settings, choices and variants. You export pile schedules to Excel or CSV.

Which systems does it run on?

In any modern browser, so also on macOS and Linux, and as an app for Windows (64-bit). Installers for macOS and Linux are not available yet.

Does it fit everyday engineering practice?

Yes. You work with the design values you already have: FEd from the structural model and Rc;net;d per CPT, pile size and tip level from the foundation advice. Pile costs per m³ are set per project.

What can an AI assistant do with it?

The Windows app can share the open project over MCP with, for example, ChatGPT Desktop or Claude Desktop. The assistant can inspect data, compare plans and run the optimiser; editing is switched on separately. The web version has no MCP.

Does the app calculate the bearing capacity itself?

No, not yet. The bearing capacity per CPT comes from the geotechnical consultant's foundation advice; the app selects, compares and optimises on that basis.

Is the optimiser's result always the best?

Not always, and you can see that. The result reports whether the optimum is proven; with Quick improve or an interrupted run you get the best solution found.

Can I try it first without my own data?

Yes. The web version opens with a complete sample project, so you can explore the workflow straight away.

Technology

For those who want to know how it is built.

Rust

The calculation core for import, pile options, CPT selection, costs and optimisation.

WebAssembly

The same Rust core runs in the browser, without a server doing the calculations.

React and TypeScript

The interface with drawing, tables and ribbon, the same in browser and desktop.

Tauri 2

A small, signed Windows app with the core running natively in Rust.

HiGHS

Open-source solver for the integer optimisation, in browser and desktop.

MCP

Local connection for AI assistants in the Windows app; changes go through the same checks and history.
