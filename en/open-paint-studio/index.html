Image editing

Open Paint Studio

Make a quick sketch or mark up a screenshot, without a heavy photo editor

Open Paint Studio is a lightweight image editor in the spirit of MS Paint. Draw with a brush, shapes and text, crop and rotate in one click, and shapes and text stay editable: move, scale or recolour them afterwards.

Features

Draw, mark up and touch up, in one lightweight app

Start with the highlights, or pick a topic.

01 Drawing and text

Sketch and write straight on the canvas

Brush, eraser, fill, eyedropper, lines, rectangles and ellipses, with adjustable size, opacity and a colour palette. Click where you want text and type; pick font, size and bold in the ribbon. The fonts ship with the app, so it works offline too.

Learn more

02 Editable shapes

Move and restyle what you have already drawn

Shapes and text remain separate objects. Select one to move it, drag the corner to scale, or give it a different colour, size or font. Ctrl+A grabs everything at once, and an SVG export keeps them editable for other programs.

Learn more

03 Editing images

Mark up a screenshot and pass it on

Open a screenshot or photo, add frames, arrows and text, and export to PNG or JPEG. Crop, resize, rotate and flip sit in one ribbon, as do brightness, contrast, saturation, greyscale, invert and sepia.

Learn more

04 Files

Opens almost any image, without uploading

PNG, JPEG, WebP and GIF, but also TIFF, HEIC from your phone, PSD, SVG, JPEG XL and camera RAW. Everything is processed on your own computer; nothing goes to the cloud. Save your work as PNG, JPEG, WebP, SVG or IFCX.

Learn more

05 AI and automation

Let an AI assistant draw along

A local API with its own token and an MCP server let an assistant such as Claude create an image, draw on it and show the result. Ask for a 1200 × 800 sketch with a coloured area, for instance; then load it in the app and carry on yourself.

Frequently asked questions

Which files can I open?

Almost any image: PNG, JPEG, WebP, GIF, BMP, TIFF, HEIC/HEIF, AVIF, PSD, SVG, ICO, TGA, JPEG 2000, JPEG XL, camera RAW and IFCX/IFCXB. For animations and multi-page files the first frame opens.

Do I need to install anything?

Yes, the app itself. On Windows it installs for your user, without admin rights; on Linux the AppImage runs without installing. There is no public web version yet.

What does Open Paint Studio cost?

Nothing. The app is free and open source under the MIT licence, with no account or subscription. The OpenAEC house style in the app is under CC BY-SA 4.0.

In which format is my work saved?

The app automatically keeps your current drawing as a draft on your own device, with all editable objects. As a file you export to PNG, JPEG, WebP or SVG, or save the image in IFCX or IFCXB.

Which systems does it run on?

Windows, macOS (Intel and Apple Silicon, one universal DMG) and Linux (.deb and AppImage). The installers are signed.

What can an AI assistant do with it?

Through the MCP server an assistant such as Claude can create images, draw on them, undo a step and show the result as a PNG. You run the API and MCP separately next to the app, from the source code; the installer does not start them for you.

Can I edit shapes and text again later from a file?

Not yet in Open Paint Studio itself. While you work on a drawing the objects stay editable, even after closing the window. IFCX stores the image as a picture; to keep editing the shapes elsewhere, export to SVG.

Do I need an internet connection?

No. The fonts and the image conversion are built into the app, and your images go nowhere. You only need the internet to download the app.

Does it replace a photo editor?

No, and it isn't meant to be. There are no layers, masks or selections of part of a photo. Open Paint Studio is for the quick jobs: sketching, marking up, cropping and a colour correction.

Technology

For those who want to know how it is built.

Tauri 2

A thin native shell in Rust for Windows, macOS and Linux, with small installers.

React, TypeScript en Vite

The editor draws on an HTML canvas; shapes and text are kept as operations.

ImageMagick (WebAssembly)

Reads TIFF, HEIC, PSD, RAW and other formats locally, in a separate worker.

IFCX en IFCXB

The image as a PNG inside an IFCX document; IFCXB is the same content as CBOR with gzip.

MCP en REST-API

An MCP server on the official TypeScript SDK and an API that only listens on your own computer, with a token and revision checks.

Signed releases

Windows installer with a digital signature, macOS app notarized by Apple, Linux packages with an OpenPGP signature and SHA256SUMS.
