Features

From model to assembly order, readable for everyone

Start with the highlights, or pick a topic.

01 Construction sequence

Show how the building goes up

Play back the assembly, or step through the model phase by phase with the slider. What is already in place keeps its colour, the current phase lights up orange and what is still to come is transparent. The order comes from each element's mark number.

02 Filtering

See only what you need

Look up an element by mark number, or tick mark ranges and element types. The rest of the model turns transparent, so you can see where those parts are.

03 Section

Look inside the building

Put a section box around the model and move its faces with the arrows. Take off a storey and see the layout and the walls underneath.

04 Explode

Pull the model apart

The exploded view moves all elements apart, as far as you choose. Ideal for showing which parts make up a prefab or timber project.

05 Selecting

Click a part and set it apart

Tap an element to see its name and mark number. Isolate or hide it with one button, or select several at once, also with a tap on a tablet.

Frequently asked questions

Which files can I open?

IFC models from any BIM program, such as Revit, Archicad or Tekla. The web version shows models stored on the Speckle server: as an uploaded IFC file or sent straight from Revit with the Speckle connector. The desktop app opens IFC files from your own computer.

Do I need to install anything?

No. Anyone with a link opens the model straight in the browser, also on a tablet or phone. To open your own IFC files without sharing them, install the desktop app.

What does Monty IFC Viewer cost?

Nothing. Viewing is free and needs no account, and the source code is public on GitHub.

Which systems does it run on?

The web version runs in any modern browser, on computer, tablet and phone. The desktop app is available for Windows (.exe and .msi), macOS on Apple Silicon (.dmg) and Linux (.deb, .rpm and AppImage).

Does it fit building practice?

Yes. It works with IFC, the open standard for BIM, and takes the order from the mark number you already fill in in Revit or in the IFC properties. For timber construction it also reads the marks of CLT elements.

How do I put my own model in the web version?

The model goes onto OpenAEC's Speckle server, as an IFC upload or from Revit. The project then gets its own link and a place on your client's project page. Contact us to set this up.

Can I open an IFC file straight in the web version?

Not yet. The web version shows shared models from the server. For a single file from your own computer, use the desktop app.

Can I see all properties of an element?

Not yet for IFC models in the web version: there the panel shows the name and the mark number. For models sent straight from Revit you also see the parameters per group.

What is the difference between the web version and the desktop app?

The web version is made for sharing: a link, a project overview, measuring, section box and filters, and it works on a tablet. The desktop app (version 1.0) opens single IFC files from your own computer and colours elements by a parameter.

Technology

For those who want to know how it is built.

Speckle Viewer

Speckle's open-source 3D viewer for display, filters, measurements, section and explode, used through its public API.

Own Speckle server

Models and versions live on speckle.open-aec.com, with IFC import and the Revit connector.

Three.js and WebGL

Smooth 3D in the browser, without a plug-in.

TypeScript and Vite

Strict, modular code without a framework, built into a static site.

Built for touch

Buttons, selection and measuring also work with a finger on tablet and phone.

Desktop with web-ifc

The desktop app reads IFC files locally with web-ifc, with signed downloads.
