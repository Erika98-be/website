Features

From the first question to the report, in one workflow

Start with the highlights, or pick a topic.

01 Building envelope

The building envelope, surface by surface

Record walls, roofs, floors and windows with orientation, slope, area and construction. Envelope checks and the transmission loss per element type show right away where the heat escapes.

Learn more

02 Installations

Installations without missing a thing

Heating, domestic hot water, ventilation, cooling and solar panels, each in fixed steps from generation to auxiliary energy. For every input you note where it comes from, such as the rating plate or the drawing.

Learn more

03 Calculation trace

Every result can be checked

The calculation trace shows, step by step, the formula, the values used, the result and the NTA 8800 formula number. Search for a surface or quantity, expand what you want to see and export the trace.

Learn more

04 Report

A report at the level you need

Choose summary, standard or detailed, and tick which calculations go in down to monthly level. Download it as a PDF, and also produce an input file and the BRL 9500 checklist.

Learn more

05 Calculation aids

U value, thermal bridge and heat pump at hand

Calculate the Rc and U value of a build-up layer by layer, with a cross-section to scale. There is also a thermal bridge calculator and an aid for sizing a heat pump.

  • Work in steps

    Project, building, installations and check: each step asks the questions that matter. Skipping is fine; the engine reports what is really missing.

  • Results update as you go

    Label class, BENG 1, 2 and 3 and TOjuli are visible at every step and recalculate with every change.

  • Zones and envelope

    Calculation zones, surfaces and windows, constructions, thermal bridges, airtightness and unheated spaces.

  • All installations

    Heating, hot water, ventilation, cooling and solar power, down to shower heat recovery.

  • A source for every input

    Link photos, drawings or rating plates to the input, so you know later where a value came from.

  • U-value calculator

    Rc and U of a wall, roof or floor, layer by layer, with a cross-section to scale.

  • Thermal bridge calculator

    Work out the effect of a thermal bridge before you enter it.

  • Heat pump sizing

    A calculation aid for the capacity a heat pump needs.

  • BENG check at a glance

    For each indicator the value, the requirement and how far above or below it you are, with points of attention and the article from the Bbl.

  • Monthly values and charts

    Energy use per service, per carrier and per month, and the heating and cooling demand, also as a table.

  • Calculation trace

    Every step with formula, values, result and formula number, searchable and exportable.

  • Where the result comes from

    Engine version, norm edition and a fingerprint of the input, plus the interpretations the engine chose.

  • Older norm editions

    Also calculate with the 2024, 2023, 2022 and 2020+A1 editions, clearly marked as not registrable.

  • Report at three levels

    Summary, standard or detailed, as a PDF or printed, with a separate report for tailored advice.

  • File in one ZIP

    Input, report and evidence together, with a manifest and a checksum per file.

  • Overview in EP-Online layout

    The data as the EP-Online export expects it, with the field limits. Registering requires an attestation first.

  • Survey of existing buildings

    Survey of existing dwellings and non-residential buildings following ISSO 82.1 and 75.1; the answers become project input.

  • Tailored advice

    Calculate measures and packages on actual use: savings, CO₂, costs, payback time and net present value.

  • Relabelling

    Compare the original and the improved project, so you see what the improvement achieves.

  • Uniec 3 and VABI

    Import projects from Uniec 3 and VABI Elements, with a list of all assumptions. Export to VABI.

  • 3D model and IFC

    View zones, surfaces, windows and solar panels in 3D and export the model as IFC.

  • API and MCP

    All 46 calculation operations through a local HTTP API or as MCP tools for an AI assistant.

  • Your projects stay with you

    The web version calculates in the browser and keeps projects there; no project data goes to a server.

  • Manual in the app

    A Dutch-language manual per topic, with a button on every page to the right chapter.

Frequently asked questions

Which files can I open?

Your own projects (.oes.json) and exchange files from Uniec 3 (.uniec3) and VABI Elements (.epa or .xml). For every import the app keeps the file name, a checksum and a list of assumptions and issues.

Do I need to install anything?

No. The web version runs straight in the browser and calculates there too: your project data does not go to a server. If you want to keep projects as files on your own disk, install the desktop app.

What does Open Energy Studio cost?

Nothing. The app is free and open source under the LGPL-3.0, with no account or subscription. The NEN and ISSO norm texts are not included; you need your own copies.

In which format is my work saved?

In an open JSON file (.oes.json). In the browser, projects are kept in that browser; the desktop app saves them as files. The project file can be exported as a ZIP.

Which systems does it run on?

Windows 10 and 11, macOS (Intel and Apple Silicon) and Linux (.deb, .rpm and AppImage), and any modern browser. The Windows installer is signed; the macOS version is not yet, so open it the first time with right-click and Open.

Does it fit Dutch practice?

Yes. It calculates following NTA 8800:2025+C1:2026 with the BENG requirements from the Bbl, and follows ISSO 82.1, 75.1, 82.2 and 75.2 and BRL 9500 for surveys and advice. Exchange with Uniec 3 and VABI is built in.

What can an AI assistant do with it?

There is an MCP server and a local HTTP API with the same 46 operations as the engine. An assistant can use them to calculate a project or consult the manual. For now you build both yourself from the source code.

Can I register an official energy label with it?

Not yet. Open Energy Studio does not (yet) hold a BRL 9501 attestation. Results are indicative and cannot be used for an official energy label, a BENG check for a permit or registration in EP-Online. The app and the reports say so too.

How do I know the result is right?

Every result carries the engine version and a fingerprint of the input, and the calculation trace shows every formula. The engine is tested against public calculation reports and the RVO example dwellings; the differences are explained item by item in the documentation.

Can I help test it?

Please do, especially if you are an energy or EPA advisor. Calculate a project you know and report differences or bugs through an issue on GitHub.

Technology

For those who want to know how it is built.

Rust calculation engine

A deterministic NTA 8800 core without I/O; every result carries the engine version and a SHA-256 of the input.

WebAssembly

The same core runs in the browser, so the web version calculates without a server.

Tauri 2

A native desktop app for Windows, macOS and Linux, with a signed Windows installer.

React and TypeScript

One interface for browser and desktop, with forms tested against the engine.

HTTP API and MCP

46 operations from one registry, as an OpenAPI 3.1 API and as MCP tools over stdio.

Verification gate

Every calculation change passes unit tests, independent recalculations from the norm text, fuzz tests and reference suites.
