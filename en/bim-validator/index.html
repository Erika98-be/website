BIM checking

BIM Validator

Know before handover whether your IFC model meets the requirements

Add an IFC model in the browser, choose the NL-BIM Basis ILS, the RVB BIM Norm or your own IDS file and click Validate. You see per requirement what passes and fails, and every failing element lights up in 3D.

Features

From IFC model to a list of errors you can fix

Start with the highlights, or pick a topic.

01 Errors in 3D

See straight away which element is wrong

Click an error in the results and the app zooms to the element while the rest of the model turns transparent. Next to it you see the requirement, type, GlobalId and name, so you can find it quickly in your own BIM software.

Learn more

02 Standards

The Dutch requirements are built in

Choose the NL-BIM Basis ILS (12 requirements) or the RVB BIM Norm of the Dutch Government Real Estate Agency (26 requirements) with one click: naming, NL/SfB codes, materials, fire resistance, U-values and more. Does your client have their own requirements? Load their IDS file.

Learn more

03 Viewing the model

Click an element and see what is in it

Orbit, zoom and click through the model without installing anything. For each element you see the storey, material, classification, property sets and quantities. Section planes let you look inside the building.

Learn more

04 BCF issues

Pass the errors on to the modeller

Turn all errors into BCF issues with one click, with your own prefix, priority, assignee and deadline. Each issue gets a viewpoint and a thumbnail. Download them as a BCF zip for Revit, ArchiCAD, Solibri or BIMcollab, or push them to the OpenAEC BCF platform.

Frequently asked questions

Which files can I open?

IFC models in IFC2X3 and IFC4, as exported from Revit, ArchiCAD, Tekla or other BIM software, up to 500 MB per file. Requirements are loaded as an IDS file (up to 5 MB).

Do I need to install anything?

Users don't: they work in the browser. Someone does need to set up the validator once on a server with Docker. There is no ready-made release and no public trial version yet.

What does it cost?

Nothing. BIM Validator is open source under the MIT licence. You only pay for your own server.

In which file format is my work saved?

A project keeps your IFC models, the results and the issues together, with a project file (.wefc) that records what belongs with what. Issues download as a BCF 2.1 zip, results as JSON; from the command line also as an HTML report.

Which systems does it run on?

Users need a modern browser with WebGL, on Windows, macOS or Linux. The server runs in Docker on Linux. There is no desktop app.

Does it fit building practice?

Yes. The Dutch NL-BIM Basis ILS and RVB BIM Norm v1.1 are built in, with NL/SfB classification. Requirements follow the buildingSMART IDS standard, issues the BCF 2.1 standard that Revit, ArchiCAD, Solibri and BIMcollab read.

What can an AI assistant do with it?

Through the REST API an assistant or script can have a model checked and fetch the results as JSON; the command line works too. There is no MCP server yet.

Do my models stay inside my organisation?

Yes. You run the validator on your own server, so models don't go to an external service. With several organisations on one server, each organisation only sees its own projects.

Can it also find clashes between models?

Not yet. The Clashes tab is already there, but clash detection has not been built yet. You can view several models together.

Technology

For those who want to know how it is built.

IfcOpenShell · IfcTester

The check itself: IfcTester tests the model against the IDS requirements, IfcOpenShell reads the IFC file.

Python · FastAPI

The server with the REST API, background checks and the ifc-validate command line.

That Open Engine · web-ifc · Three.js

The 3D viewer in the browser, with fragments for fast display of large models.

React · TypeScript · Vite

The interface with ribbon, panels and themes, in Dutch and English.

PostgreSQL · Nextcloud

Projects in PostgreSQL (SQLite for local testing) and files in Nextcloud via WebDAV.

Docker · OIDC

A single Docker Compose setup with optional sign-in via OpenID Connect.
