Open Calculations Studio

Calculations your colleague can check in one read

Write your calculation as text with units and see the worked-out result at once: formula, substituted values and outcome on one line. Start from a sheet for concrete, steel, timber, masonry or foundations, right in the browser.

Features

Calculate, check and have it reviewed

Start with the highlights, or pick a topic.

01 Calculating

Write the calculation the way you would on paper

Type a formula with units, such as d_eff = (d_y + d_z) / 2. The worked-out result appears at once as proper maths: formula, substituted values and outcome on one line, with the unit. Conditions pick the right formula, for example per column type.

02 Code sheets

Start from a code sheet instead of a blank page

Over fifty sheets per clause, from the load combinations in NEN-EN 1990 to bending, buckling and deflection in concrete, steel and timber, masonry and pile bearing capacity to NEN 9997-1. With full checks of a concrete beam, a steel beam and a timber beam.

03 Input

Pick and fill in, the result follows

A sheet can ask for input: a drop-down list for wind zone, strength class or consequence class, or a field for a height or span. Change a choice and the whole worked-out result recalculates at once.

04 Reviewing

Every step visible, no black box

Hide the editor and read only the worked-out result, with the clause numbers of the code alongside. Whoever checks the calculation sees exactly which formula with which values leads to the unity check.

  • Calculating with units

    mm, kN, N/mm², mm⁴ and all SI units. b*h becomes mm² by itself; 'to' converts to the unit you want.

  • Formula, values and outcome

    Every line shows name = formula = substituted values = result, with proper fractions, roots and Greek letters.

  • Live result

    Text on the left, result on the right. What you type is calculated straight away.

  • Conditions and loops

    #if, #else if and #else for 'passes' or 'fails', and #repeat and #for for series.

  • Your own functions and tables

    Macros with #def, matrices and lookup tables for material values.

  • CalcPAD syntax

    If you know CalcPAD, you will recognise the structure: headings, text lines, comments and commands work the same way.

  • Basis and combinations

    NEN-EN 1990: ultimate and serviceability limit states, EQU, accidental, seismic and design values.

  • Loads

    Imposed loads, snow and wind to EN 1991 with the Dutch annex, including a taller building nearby.

  • Concrete

    Bending, shear with and without stirrups, punching, crack width and deflection to EN 1992-1-1.

  • Steel

    Cross-section class, tension, compression, bending, shear, buckling, lateral-torsional buckling and bottom-flange bending to EN 1993-1-1.

  • Timber

    Bending, shear, compression, torsion, buckling, tapered beam, notch, deflection and floor and roof sheathing to EN 1995-1-1.

  • Masonry

    Compressive strength, wall in compression, shear and slenderness to EN 1996-1-1.

  • Foundations

    Strip footing, pile bearing capacity, settlement and sliding to NEN 9997-1.

  • Worked examples

    Examples from Vandepitte on shear stresses, deflection, buckling, natural frequency and virtual work.

  • Drop-down lists

    Choose consequence class, strength class, service class or pile type from a list; the calculation follows.

  • Input fields

    Values that differ per project, such as a height or a load, go into a field in the worked-out result.

  • Read a cone test

    A sheet can ask for a GEF file, so you can use the cone test data in your foundation calculation.

  • Three views

    Text and result side by side, the editor only or the result only.

  • Colour-coded editor

    Line numbers and colours for headings, commands and drop-down lists, so you keep track of long calculations.

  • No account

    Open the page and start. Your calculation runs in your own browser.

Frequently asked questions

Which files can I open?

In the browser version you start from a sheet in the library or type your own. You can paste a calculation in CalcPAD syntax into the editor. A sheet can read a cone test as a GEF file. Opening files through the menu does not work in the browser yet.

Do I need to install anything?

No. The browser version works straight away, without an account. There is also a desktop app for Windows, macOS and Linux, with projects, calculation modules and a structural report, but its installers are not public yet.

What does Open Calculations Studio cost?

Nothing. The browser version is free, with no account or subscription.

In which format is my work saved?

Not yet in the browser version: saving and exporting to PDF, IFC, HTML or JSON do not work there yet. Copy your text to keep it. The desktop app saves a project as an .ifccalculation file.

Which systems does it run on?

In any modern browser, on Windows, macOS and Linux. The calculating happens in your own browser.

Does it fit Dutch practice?

The sheets follow the Eurocodes with the Dutch national annexes and NEN 9997-1, with the clause numbers alongside. Always check the result yourself. In the desktop app, only the timber joist floor and the emergency roof overflow have been reviewed and released so far; the other modules are still marked for checking.

Can I export to IFC?

Not yet in the browser. The calculation engine can write a calculation as IFC4x3 and IFCX, so a check belongs to the right element in the BIM model; that is part of the desktop app.

Is the source code public?

Not yet. The repository on GitHub is not public yet; that is why this page has no downloads yet.

How does it relate to CalcPAD?

Open Calculations Studio is inspired by CalcPAD and supports a large part of its syntax: headings, text, conditions, loops, macros and plots. It runs in the browser, so on macOS and Linux too.

Technology

For those who want to know how it is built.

Own calculation engine

Parser, evaluator and renderer in TypeScript, also usable as a library in other software.

mathjs

Calculating with units and matrices, with automatic simplification of the unit.

KaTeX

Formulas as clean maths, with fractions, roots, subscripts and superscripts.

CodeMirror 6

The editor with line numbers and colours for the calculation syntax.

IFC4x3 and IFCX

The engine turns a calculation into IFC4x3 STEP and IFCX JSON-LD.

Vite and Tauri 2

Vite builds the browser version; the desktop app uses a thin native shell in Rust.
