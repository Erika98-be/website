2D drafting

Open 2D Studio

From the first line to a print-ready sheet, right in the browser

Draw floor plans, details and technical drawings with the tools you know from CAD: layers, snapping, dimensions and hatches. Place your drawing to scale on a sheet with a title block, then print it or save it as PDF or DXF.

Features

Draw, dimension and print

Start with the highlights, or pick a topic.

01 Drawing

Draw the way you are used to in CAD

Line, polyline, rectangle, circle, arc, ellipse and spline, with snapping to endpoint, midpoint, centre and intersection. Move, copy, rotate, mirror, trim or fillet, and adjust colour, lineweight and line style in the properties panel.

02 Layers

Layers keep your drawing clear

Put walls, frames, furniture and dimensions each on their own layer with their own colour. Switch a layer off to work without it for a while, or lock it so you don't draw on it by accident.

03 Hatches

A hatch for every material

Choose from 47 built-in patterns, from diagonal and cross-hatching to concrete, or make your own pattern. Keep your favourites, and import and export patterns to share them with colleagues.

04 Sheets

From drawing to sheet with a title block

Place your drawing to scale on a sheet from A4 to A0, portrait or landscape. Fill in the title block with title, drawing number, project, scale and date, or start from a sheet template.

05 Printing

Print or save as PDF

Choose the paper size, portrait or landscape, the margins and what to print: the current view or a selection of sheets. You see a preview straight away, and save your settings as a preset for next time.

06 Exchange

Works with other CAD and BIM software

Read and write DXF for AutoCAD, BricsCAD and other CAD programs, and export to SVG, JSON and IFC4. The IFC panel shows live how your drawing is written out as IFC.

Frequently asked questions

Which files can I open?

Your own project files (.o2d) and DXF files from AutoCAD, BricsCAD or another CAD program. You can use a PDF or a large DXF file as an underlay, and insert images. Open 2D Studio does not open DWG files yet; save them as DXF in your CAD program first.

Do I need to install anything?

No. The browser version works straight away, without an account. There are also versions for Windows, macOS, Linux and Android tablets, but they are not yet available for public download.

What does Open 2D Studio cost?

Nothing. You pay no licence fee and need no account or subscription.

In what format is my work saved?

As an .o2d project file, with all your drawings, sheets and layers. In the browser you download that file. You can also export to DXF, SVG, JSON and IFC4, and to PDF via the print dialog.

Which systems does it run on?

In any modern browser on Windows, macOS and Linux. Desktop versions for Windows, macOS and Linux and an Android app for tablets exist, but are not public yet.

Does it fit construction practice?

You work in millimetres at a scale such as 1:50 or 1:100, with paper sizes from A4 to A0, a title block, and text and dimensions in an ISO typeface. The interface is in English for now.

What can an AI assistant do with it?

Every draw, modify and layer command is described as a tool for AI assistants. In the desktop version you type a request in plain language in the terminal, such as "draw a circle", and Claude Code on your own computer carries it out. This does not work in the browser yet, and there is no MCP server to connect to yourself yet.

How is it different from Open CAD Studio?

They are two separate programs by different makers. Open CAD Studio is built to open and update DWG and DXF files from others, in 2D and 3D. Open 2D Studio focuses on drawing in 2D yourself: layers, dimensions, hatches and sheets with a title block. If you mostly work with DWG files from others, take a look at Open CAD Studio.

Is the source code public?

Not yet. Open 2D Studio carries the LGPL-3.0 licence, but its GitHub repository is not public yet. That is why this page has no downloads yet.

Is it still being worked on?

The latest version, v0.35, dates from March 2026. The browser version went online in April; since then there have only been small maintenance changes. If you miss something, report it with F1 in the app.

Technology

For those who want to know how it is built.

Tauri 2

A thin native shell in Rust for Windows, macOS, Linux and Android, with an installer of a few megabytes.

React 19 en TypeScript

The interface in separate components with type checking; Zustand keeps track of the drawing state.

Canvas 2D

Own drawing engine on the HTML canvas, with snapping, grips and selection.

DXF

Own DXF reader and writer in TypeScript, so exchange works in the browser too.

jsPDF en pdf.js

Vector PDF for printing, and reading PDF files as an underlay.

Osifont

Open typeface to ISO 3098 for text and dimensions.
