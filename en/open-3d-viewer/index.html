Open 3D Viewer Studio

Open any building model you receive, without the program that made it

Drop a SketchUp, Tekla, DWG or glTF file in your browser, or open IFC and Revit in the desktop app. Walk around the model, measure, cut it open and save it as IFC.

Features

View, measure and section in one window

Start with the highlights, or pick a topic.

01 Measure

Measure right in the model

Click two points, edges or faces and read the distance, with the difference in X, Y and Z. Angles, areas, volumes and polygons too. Measurements stay in view until you clear them.

Learn more

02 Sections

Look inside with a section

A section box or section plane cuts the model open, with filled cut faces. Slide each axis until you look at exactly the floor you need.

Learn more

03 Exploded view

See how it fits together

Pull the model apart, per storey or per element, by a percentage per axis. One view shows how a bathroom or a building is put together.

Learn more

04 Workspace

Work the way you like

Pick one of five themes, from light and dark to Blueprint and high contrast. Top, front and side views and an orthographic camera are one key away, and every command can get the shortcut you want.

Learn more

  • Orbit, pan and zoom

    Left drag orbits, middle drag pans, the wheel zooms to the cursor. F fits the whole model in view.

  • View cube and standard views

    Turn the model to a side with the view cube. Iso, top, front and right on 0 to 3, perspective or orthographic on P and O.

  • Solid, wireframe or with edges

    Switch between the render modes with S, W and E, and toggle the grid with G.

  • Layers on and off

    The explorer lists the layers with colour and count: IFC layers, Revit categories, SketchUp tags, Tekla classes or CAD layers. Turn them on or off one by one.

  • Properties of an element

    Click an element and read its properties. For the file you see the format, size, triangle count and dimensions.

  • Other up axis

    Is a model lying on its side because the file uses another up axis? One click stands it upright.

  • Distances and angles

    Measure between points, edges and faces, or between two elements. Every distance shows the difference in X, Y and Z.

  • Area, volume and polygon

    Measure an area or volume, or click a polygon. Choose the unit (mm, cm or m) and the number of decimals.

  • Section box and section plane

    Cut the model open with a box or a plane, with filled cut faces. The box can fit the selection.

  • Exploded view

    Pull the model apart per storey or per element, by a percentage per axis.

  • Open IFC and Revit

    The desktop app opens IFC and Revit (.rvt, .rfa), with levels, grids, rooms and saved views. IFC spaces start hidden in a layer of their own.

  • Revit schedules as a table

    A schedule from a Revit file opens as a table under the 3D view. Click a row and its elements are selected.

  • SketchUp, Tekla and DWG/DXF

    SketchUp from version 3, Tekla Structures (beta) and the faces of DWG and DXF drawings, in the browser and on the desktop.

  • CityJSON and LandXML

    Buildings from a CityJSON city model, at the highest level of detail per object, and terrain surfaces (TIN) from LandXML.

  • glTF, OBJ, STL and PLY

    The common 3D formats from design, scanning and printing software open too.

  • Several models at once

    Open replaces the model, Add puts another file next to it. Each model has its own eye to show or hide it.

  • Save as IFC

    Save any model the viewer opens as IFC 4, with storeys, classes, properties and materials. In the browser the file goes to your downloads.

  • Five themes

    Light, dark, Blueprint and two high-contrast variants, in the same window as the other OpenAEC apps.

  • Your own shortcuts

    Every command is in one list, shared by the ribbon, the title bar and the keyboard. Give any command your own key in the settings.

  • Dutch and English

    Choose the language of the window in the settings.

  • Let an AI assistant drive it

    Through the MCP server an AI assistant opens files, turns the camera, finds elements by property, measures and sections, in the window you see.

  • Your model stays with you

    Even in the browser nothing is uploaded: the file is read on your own computer.

  • Signed downloads and updates

    Every installer is signed. When the OpenAEC Installer has a newer version, the title bar says so and Update installs it.

Frequently asked questions

Which files can I open?

IFC and Revit (.rvt, .rfa) in the desktop app. SketchUp (version 3 and later), Tekla Structures (.db1, beta), DWG/DXF, CityJSON, LandXML, glTF, OBJ, STL and PLY in the desktop app and in the browser. Point clouds (E57, LAS), FBX, STEP and IGES do not open yet.

Do I need to install anything?

No. The browser version works in a current Chrome, Edge, Firefox or Safari with WebGPU. For IFC and Revit, and to connect an AI assistant, install the desktop app, most easily with the OpenAEC Installer.

What does it cost?

Nothing. The viewer is free, with no account and no licence fees. The source code is LGPL-3.0; for Revit the desktop app uses an OpenAEC library with a licence of its own.

In which file format is my work saved?

The viewer does not change your file. Save as stores the model as IFC 4, with storeys, classes, properties and materials. Elements are written as triangles, not as parametric geometry.

Which systems does it run on?

Windows 10 and 11 (x64), macOS 11 or later (Apple silicon and Intel) and Linux (.deb, .rpm, AppImage), and in any browser with WebGPU.

Does it fit building practice?

Yes. You open what you are sent from Revit, SketchUp, Tekla and CAD, and turn it into IFC 4 for an openBIM workflow. The IFC export is checked with IfcOpenShell. Classes come from the Revit category or the Tekla part; elements of an opened IFC file do not keep their class yet.

What can an AI assistant do with it?

With the MCP server that comes with the desktop app, Claude or another MCP client drives the viewer as you do: open files, take screenshots, choose views and layers, find and select elements, measure, section, explode and read Revit schedules. It stays on your own computer.

Why does IFC not open in the browser?

The IFC and Revit readers are not in the browser version yet. Use the desktop app for those. In the browser, .gltf files need their buffers embedded, and OBJ materials are not read yet.

Is my model uploaded?

No. Even in the browser the file is read on your own computer; nothing goes to a server.

What does it not do yet?

There is no undo, walk mode or hidden-line view yet. Textures become their average colour. The browser version freezes briefly while loading a large model and does not remember your settings yet.

Technology

For those who want to know how it is built.

Rust

One code base for the desktop app, the browser version and the MCP server.

iced 0.14

The interface, native and as WebAssembly, without a web view or JavaScript framework.

wgpu · WebGPU

An own 3D pipeline with 4x MSAA; the same code draws on the desktop and in the browser.

IFClite · acadrust

IFC through IFClite, DWG/DXF through acadrust, and OpenAEC's own readers for SketchUp, Tekla, PLY and Revit.

OpenAEC Blueprint

The window, design tokens, fonts and icons from the shared openaec-ui crate.

MCP

open-3d-viewer-mcp drives the window on your screen over 127.0.0.1 with a random token.
