BCF Manager Studio

All BIM issues of a project in one place, on your own server

BCF Manager Studio is a concept for issue management in BIM projects. You collect the findings from model checks per project, discuss them with your team and pass them on as a BCF file to any other BIM software.

Features

From finding to fix, with the whole team

Start with the highlights, or pick a topic.

01 Projects

Every project its own issue list

Create one place per project for all findings, with a name, location, description and a project image. The overview shows at a glance which building it is, and nobody has to search through loose e-mails and spreadsheets any more.

02 Overview

See in one list what is still open

Every issue is listed with its status, priority and type, such as clash, issue or remark. The dashboard counts the open, ongoing and closed issues and shows per priority where the work is.

03 View from the model

See right away where the problem is

Every issue shows the snapshot from the model, with the camera position. The viewpoint refers to the elements by their IFC GlobalId, so a BCF viewer jumps straight to the right part.

04 Collaboration

Discuss the issue where it belongs

Comments sit on the issue itself, with date and time, so the whole discussion stays together. Next to them you see who it is assigned to, the deadline, the stage and the labels.

  • Create projects

    With a name, location and description, and a project image of your own.

  • New issue

    Title, description, type, status and priority in one form.

  • Status and priority

    Open, active, closed or reopened; from low to critical, as BCF defines them.

  • Dashboard per project

    The number of open, ongoing and closed issues, and a bar chart per priority.

  • Filtering

    Show only the issues with a given status or priority on the dashboard.

  • Snapshots on every issue

    The image from the model is shown large on the issue and small on the dashboard cards.

  • Camera position

    Perspective or orthographic, with the camera position as stored in the viewpoint.

  • Elements by IFC GlobalId

    Selection, visibility and colouring per element, so a viewer shows the right part.

  • Comments

    Write a comment on the issue; every comment gets a date and time.

  • Assignment and deadline

    Who the issue is assigned to, the deadline, the stage and the labels, as they come from the BCF file.

  • Members per project

    Add colleagues to a project as owner, administrator, member or viewer.

  • Single sign-on

    Your team signs in with the organisation's existing account.

  • Import BCF files

    Read in a .bcfzip with all issues, comments and viewpoints, for example from a model check.

  • Export BCF files

    Download all issues of a project as a .bcfzip for any BCF software.

  • BCF API 2.1

    The open standard API for projects, issues, comments and viewpoints, for links with other software.

  • API keys per project

    Give a script or checking tool access to one project, optionally with an expiry date.

  • Save to your Nextcloud

    Keep the issues as a .bcfzip in the project folder, next to the IFC models, and open them from there again.

  • Project manifest kept up to date

    On saving, the issue set is added to the project manifest, so other OpenAEC apps can find it.

  • On your own server

    One Docker installation with a database; your project data never leaves your own environment.

  • Several organisations

    One installation can serve several organisations, each with its own Nextcloud.

  • Familiar ribbon

    The same ribbon as the other OpenAEC apps, with shortcuts for import (Ctrl+I) and export (Ctrl+E).

Frequently asked questions

Which files can I open?

BCF files (.bcfzip) in version 2.1, as written by Solibri, Navisworks, BIMcollab, Revit and the OpenAEC apps. BCF 3.0 is not supported yet. BCF Manager Studio does not open the IFC model itself; use an IFC viewer for that.

Do I need to install anything?

Yes, on a server. BCF Manager Studio is a server application that you put on your own server with Docker, together with PostgreSQL. Your team then simply works in the browser. There is no ready-made release yet, and the online trial version was shut down on 8 October 2026.

What does it cost?

Nothing. The source code is public on GitHub and you only pay for your own server. There is no licence file with the source code yet; it will come with the first release.

In which file format is my work saved?

The issues are stored in a PostgreSQL database on your server, with the snapshots as images alongside. You can export them at any time as a .bcfzip, the open buildingSMART standard, or save them that way to your Nextcloud.

Which systems does it run on?

The server runs in Docker, on Linux. Your team works in a modern browser on Windows, macOS or Linux.

Does it fit construction practice?

Yes. BCF is the open buildingSMART standard for BIM coordination: a model check produces issues, which you discuss, assign and close. Statuses, priorities, stages and labels follow BCF 2.1, so they stay intact when you exchange them with other parties.

What can an AI assistant do with it?

There is no MCP server yet. An assistant or script with an API key can, however, read and create issues, comments and viewpoints of a project through the BCF API 2.1.

Can I use it yet?

Not out of the box. BCF Manager Studio is a concept: there is no release and no public trial version any more, and development has been paused since April 2026. If you want, you can build it yourself from the source code on GitHub and put it on your own server.

Can I edit an issue on screen?

Partly. On screen you create issues and write comments. You cannot yet change the status, assignment and deadline of an existing issue on screen, but you can through a BCF import or the API. Searching the issue list is still to come as well.

Does it work with Revit?

Through BCF files, yes: you simply read in a .bcfzip from Revit. There is also a separate test version of a Revit 2025 plug-in that opens .bcfzip files in Revit. A direct connection between that plug-in and BCF Manager Studio does not work yet.

Technology

For those who want to know how it is built.

Rust · Axum

Fast, lean server in Rust with Axum and Tokio.

React · TypeScript

Web interface with Vite and Tailwind, in the OpenAEC house style.

BCF 2.1 · BCF API 2.1

Own Rust library that reads and writes .bcfzip, plus the standard buildingSMART API.

PostgreSQL 16 · Docker

Database with migrations; everything starts with Docker Compose behind Caddy.

OIDC · JWT · API keys

Single sign-on through Authentik, JWT sessions and keys per project.

Nextcloud · WebDAV

Storage in your own Nextcloud through the shared openaec-cloud library, with .wefc manifests.
