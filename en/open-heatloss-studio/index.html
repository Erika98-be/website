Heat loss

Open Heatloss Studio

Room-by-room heat loss following ISSO 51, without licence fees

Enter the temperature, ventilation and boundary surfaces per room and calculate the required heating capacity. Build up constructions with the Rc calculator, check ventilation and the cooling demand in July, and keep everything in an open IFCX file.

Features

From room to required heating capacity, in one app

Start with the highlights, or pick a topic.

01 Rooms

All rooms in one overview

For each room the function, design temperature, area and height, and below it every boundary surface: external wall, window, floor or neighbouring dwelling, with area and U value. Ventilation and heating are set in the same row.

Learn more

02 Results

See straight away where the heat escapes

One click on Calculate gives the required heating capacity, the split between transmission, ventilation and reheat allowance, and a chart per room. Click a chart to view it full size.

Learn more

03 Constructions

Work out a construction layer by layer

Build up a wall, floor or roof from over 150 materials and see the Rc and U value straight away following ISO 6946, with a correction for fasteners. The Glaser diagram shows whether interstitial condensation is a risk.

Learn more

04 Ventilation

Ventilation requirements checked per room

Choose ventilation system A to D and see, per room, the requirement from the Dutch Building Decree (Bbl) next to what is provided. Assign heat recovery or extract units and check whether their capacity is sufficient.

Learn more

05 Summer

Cooling demand in July, checked quickly

The TO-juli check for dwellings following NTA 8800 Annex AA takes the data from your project and gives the minimum cooling capacity and the governing cooling demand. For other buildings there is the full calculation from chapter 10.

Learn more

06 Open files

Your project as open IFC

Your project is saved as .ifcenergy, an IFCX file. On the IFC tab you also see it live as IFC4X3, with rooms, walls, floors and roofs, ready to copy or download.

Learn more

  • Calculation following ISSO 51:2023

    Transmission, ventilation, infiltration, reheat allowance and system losses per room, including the 2023 erratum.

  • Every kind of boundary

    Outside air, ground, unheated space, another room, a neighbouring dwelling and even water, for houseboats.

  • Results per room

    Required capacity, breakdown and charts per room and for the whole building.

  • Building settings

    Building type, night setback and warm-up time, heating system and airtightness (qv10).

  • Zones

    Group rooms into zones and manage them from the project.

  • PDF report

    Cover, starting points, construction build-ups, results per room and charts; each section on or off, on A4 or A3.

  • Rc calculator

    Rc and U following ISO 6946, with a correction for fasteners (Annex F).

  • Vapour pressure and moisture balance

    Glaser diagram and an annual moisture balance following NEN-EN-ISO 13788, with climate years from Dutch weather stations.

  • Library of build-ups

    Ready-made cavity walls, timber-frame walls, floors and roofs, with over 150 materials. Add your own build-ups.

  • U value of a window

    Combined Uw of glazing, frame and edge seal following NEN-EN-ISO 10077-1.

  • Ventilation balance to the Bbl

    Requirement per room and building balance for systems A to D, in dm³/s and m³/h.

  • Heat recovery and extract units

    Pick a unit from the catalogue or add your own; the app checks the capacity.

  • Door gap calculator

    The gap under an internal door for transferring ventilation air, following NEN 1087.

  • TO-juli following NTA 8800

    Quick check for dwellings (Annex AA) and the full calculation from chapter 10.

  • BENG 1, 2 and 3

    Energy performance following NTA 8800 with heating, hot water, ventilation, cooling and solar panels; compare with a Uniec 3 file.

  • Open project file

    .ifcenergy based on IFCX. Older .isso51.json files open too.

  • IFC4X3 and JSON

    Download your model as IFC4X3 with rooms and constructions, or the results as JSON.

  • IFC reconstruction (beta)

    Load an IFC model and get the areas per room and boundary, with a 3D view and CSV export.

  • Import from Revit

    Take over rooms and boundaries from a Revit model through the pyRevit export and an import wizard.

  • MCP server and REST API

    Let an AI assistant or your own script calculate a project, read files and create a PDF report.

  • Projects in tabs

    Work on several projects at once, each with its own undo and redo.

  • Extra calculators

    Rainwater drainage per roof surface, car park ramps (NEN 2443), angles and slopes, and material expansion.

Frequently asked questions

Which files can I open?

Projects in .ifcenergy (IFCX) and older .isso51.json files. You can also read a thermal export from Revit (via pyRevit), an IFC model for the IFC reconstruction and a Uniec 3 file for BENG.

Do I need to install anything?

No, the app runs in the browser. For Windows there is a test build (alpha) among the releases on GitHub. It is not signed yet, so Windows shows a warning first.

What does Open Heatloss Studio cost?

Nothing. The app is free and open source under the MIT licence. You need no account or subscription to calculate.

In which format is my work saved?

In .ifcenergy, an open IFCX file (IFC5 alpha) with your rooms, constructions and results. You can also export IFC4X3 and JSON.

Which systems does it run on?

In any modern browser, and as a test build on Windows. There is no downloadable version for macOS and Linux yet.

Does it fit Dutch practice?

Yes. The calculation follows ISSO 51:2023 with its erratum, the ventilation requirements come from the Dutch Building Decree (Bbl) and the cooling demand from NTA 8800. The calculation core is tested against three reference projects, including the worked example from ISSO 51. The app is still in testing: check the results before you use them.

What can an AI assistant do with it?

There is an MCP server (Model Context Protocol) for Claude Desktop and Claude Code. With it, an assistant can calculate a project, read an .ifcenergy file, look up constructions and create a PDF report. For your own scripts there is a REST API.

Can I calculate non-residential buildings too?

Not fully yet. In the settings you can switch to ISSO 53 for non-residential buildings, but that calculation is still under development.

Can I draw the floor plan?

Not yet. The Modeller currently only shows the rooms in 2D and 3D; drawing comes in a later version. You enter rooms in the table or take them over from Revit or IFC.

Technology

For those who want to know how it is built.

Calculation core in Rust

ISSO 51, ISSO 53 and NTA 8800 in pure Rust, with regression tests on reference projects.

Tauri 2

A thin native shell for the desktop app, which calculates and creates PDFs locally.

React and TypeScript

The same interface in the browser and on the desktop, with ribbon, tabs and charts.

IFCX and IFC4X3

The project file is IFCX (IFC5 alpha); the IFC4X3 export needs no Python.

openaec-layout

Reports as PDF through the shared OpenAEC report engine, with embedded fonts.

MCP and REST API

An MCP server in TypeScript and a REST API in Rust (Axum) for integrations.
