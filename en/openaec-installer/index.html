OpenAEC Installer

Install, update and launch every OpenAEC app from one place

The Installer knows every app of the OpenAEC Foundation. It sees what is on your computer, puts the latest version in place in one click and keeps everything up to date. The web tools open in their own tab.

Features

The whole OpenAEC ecosystem, at hand

Start with the highlights, or pick a topic.

01 Updates

Always the latest version, without searching

Every card shows the version you have and the one that is ready. One click updates an app, or all of them at once. The Installer waits until you have closed the app, so you lose no work, and starts it again afterwards.

Learn more

02 Discover

Find the app that fits your trade

Every app in the ecosystem is in one catalogue, with a short description and a picture. Filter by architecture, engineering, construction or infra, by what you already have or by updates, or search by name.

Learn more

03 Web tools

Web tools in a tab, without installing

Web tools and the web versions of the desktop apps open in tabs inside the Installer. Switch between them without losing your place; your tabs are back the next time you start. Prefer your own browser? That works too.

Learn more

04 Appearance

In the style of every OpenAEC app

Choose from five themes, including Blueprint and two with high contrast, and from three text sizes. The Installer speaks Dutch and English and follows the language of your computer.

Frequently asked questions

Do I need to install anything?

Yes, the Installer itself: a small desktop app of about 5 MB on Windows. Then you install the other apps from the Installer. The web tools need nothing.

What does the OpenAEC Installer cost?

Nothing. The Installer is free and open source under the CC BY-SA 4.0 licence, with no account or subscription. The apps it installs are free too.

Which systems does it run on?

Windows, macOS (Intel and Apple Silicon) and Linux (.deb, AppImage and Snap). Installing, updating and launching apps works on Windows and Linux. On macOS the catalogue and the web tools work; installing apps is not possible there yet.

Which apps can I install with it?

Fourteen desktop apps, including Open PDF Studio, Open Planner Studio, Open Calc Studio, Open Geotechniek Studio, Open Pointcloud Studio and Monty IFC Viewer, and five web tools such as Open Energy Studio and OpenBooks. When an app is added, it appears in the catalogue after an Installer update.

Where do the downloads come from?

Always from the app's official releases on GitHub. If an app ships a digital signature, the Installer checks it while downloading and starts nothing if it is missing or wrong.

Do I lose work when an app is updated?

No. If the app is open, the Installer asks you to close it and waits; it never closes it itself. After the update the app starts again.

Do I need admin rights?

Usually not. The Installer installs per user, and on Linux apps go into your own folder. Only an app installed for the whole computer asks for admin rights when it is updated.

Technology

For those who want to know how it is built.

Tauri 2 · Rust

A small native app for Windows, macOS and Linux; Rust handles the downloads, the checks and the installation.

React · TypeScript

The interface, built with the web package of the OpenAEC design 0.4: tokens, fonts and icons.

GitHub Releases

One release feed for all apps, with the GitHub API as a fallback and a one-hour cache.

Minisign signatures

A signed latest.json per app, in the same format as the Tauri updater, with a release kit for the apps.

Windows: NSIS · MSI · Inno Setup

Detection through the registry, silent updates in the same kind of setup, per user or for the whole computer.

Linux: AppImage

A managed folder in ~/.local/share with menu entries following the XDG standard, without admin rights.
