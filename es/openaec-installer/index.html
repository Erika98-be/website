OpenAEC Installer

Instala, actualiza e inicia todas las aplicaciones de OpenAEC desde una sola aplicación

El Installer conoce todas las aplicaciones de la OpenAEC Foundation. Ve lo que hay en tu ordenador, instala la última versión con un clic y lo mantiene todo al día. Las herramientas web se abren en su propia pestaña.

Preguntas frecuentes

¿Tengo que instalar algo?

Sí, el propio Installer: una pequeña aplicación de escritorio de unos 5 MB en Windows. Después instalas las demás aplicaciones desde el Installer. Las herramientas web no necesitan nada.

¿Cuánto cuesta el OpenAEC Installer?

Nada. El Installer es gratuito y de código abierto con la licencia CC BY-SA 4.0, sin cuenta ni suscripción. Las aplicaciones que instala también son gratuitas.

¿En qué sistemas funciona?

Windows, macOS (Intel y Apple Silicon) y Linux (.deb, AppImage y Snap). Instalar, actualizar e iniciar aplicaciones funciona en Windows y Linux. En macOS funcionan el catálogo y las herramientas web; instalar aplicaciones todavía no es posible allí.

¿Qué aplicaciones puedo instalar con él?

Catorce aplicaciones de escritorio, entre ellas Open PDF Studio, Open Planner Studio, Open Calc Studio, Open Geotechniek Studio, Open Pointcloud Studio y Monty IFC Viewer, y cinco herramientas web como Open Energy Studio y OpenBooks. Cuando se añade una aplicación, aparece en el catálogo tras una actualización del Installer.

¿De dónde vienen las descargas?

Siempre de las versiones oficiales de la aplicación en GitHub. Si una aplicación incluye una firma digital, el Installer la comprueba durante la descarga y no inicia nada si falta o no es correcta.

¿Pierdo trabajo cuando se actualiza una aplicación?

No. Si la aplicación está abierta, el Installer te pide que la cierres y espera; nunca la cierra él mismo. Después de actualizar, la aplicación vuelve a iniciarse.

¿Necesito permisos de administrador?

Normalmente no. El Installer se instala por usuario, y en Linux las aplicaciones van a tu propia carpeta. Solo una aplicación instalada para todo el ordenador pide permisos de administrador al actualizarse.

Tecnología

Para quien quiera saber cómo está hecho.

Tauri 2 · Rust

Una pequeña aplicación nativa para Windows, macOS y Linux; Rust se encarga de las descargas, las comprobaciones y la instalación.

React · TypeScript

La interfaz, hecha con el paquete web del diseño OpenAEC 0.4: tokens, fuentes e iconos.

GitHub Releases

Un solo feed de versiones para todas las aplicaciones, con la API de GitHub como respaldo y una caché de una hora.

Firmas minisign

Un latest.json firmado por aplicación, en el mismo formato que el Tauri updater, con un kit de publicación para las aplicaciones.

Windows: NSIS · MSI · Inno Setup

Detección mediante el registro, actualizaciones silenciosas en el mismo tipo de instalador, por usuario o para todo el ordenador.

Linux: AppImage

Una carpeta gestionada en ~/.local/share con entradas de menú según el estándar XDG, sin permisos de administrador.
