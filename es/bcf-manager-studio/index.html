BCF Manager Studio

Todas las incidencias BIM de un proyecto en un solo lugar, en tu propio servidor

BCF Manager Studio es un concepto de gestión de incidencias en proyectos BIM. Reúnes por proyecto los hallazgos de las comprobaciones del modelo, los comentas con tu equipo y los pasas como archivo BCF a cualquier otro programa BIM.

Funciones

Del hallazgo a la solución, con todo el equipo

Empieza por lo más destacado o elige un tema.

01 Proyectos

Cada proyecto con su propia lista de incidencias

Crea por proyecto un único lugar para todos los hallazgos, con nombre, ubicación, descripción e imagen del proyecto. La vista general muestra de un vistazo de qué edificio se trata, y nadie vuelve a buscar en correos y hojas de cálculo sueltos.

02 Vista general

Ve en una sola lista lo que sigue abierto

Cada incidencia aparece en la lista con su estado, prioridad y tipo, como colisión, incidencia u observación. El panel cuenta las incidencias abiertas, en curso y cerradas, y muestra por prioridad dónde está el trabajo.

03 Vista del modelo

Ve enseguida dónde está el problema

Cada incidencia muestra la captura del modelo, con la posición de la cámara. El punto de vista remite a los elementos por su IFC GlobalId, de modo que un visor BCF salta directamente a la pieza correcta.

04 Colaboración

Comenta la incidencia donde corresponde

Los comentarios están en la propia incidencia, con fecha y hora, para que toda la conversación quede junta. Al lado ves a quién está asignada, la fecha límite, la fase y las etiquetas.

  • Crear proyectos

    Con nombre, ubicación y descripción, y una imagen propia del proyecto.

  • Nueva incidencia

    Título, descripción, tipo, estado y prioridad en un solo formulario.

  • Estado y prioridad

    Abierta, activa, cerrada o reabierta; de baja a crítica, como las define BCF.

  • Panel por proyecto

    El número de incidencias abiertas, en curso y cerradas, y un gráfico de barras por prioridad.

  • Filtrar

    Muestra en el panel solo las incidencias con un estado o prioridad concretos.

  • Capturas en cada incidencia

    La imagen del modelo aparece en grande en la incidencia y en pequeño en las tarjetas del panel.

  • Posición de la cámara

    Perspectiva u ortográfica, con la posición de la cámara guardada en el punto de vista.

  • Elementos por IFC GlobalId

    Selección, visibilidad y coloreado por elemento, para que un visor muestre la pieza correcta.

  • Comentarios

    Escribe un comentario en la incidencia; cada comentario lleva fecha y hora.

  • Asignación y fecha límite

    A quién está asignada la incidencia, la fecha límite, la fase y las etiquetas, tal como vienen del archivo BCF.

  • Miembros por proyecto

    Añade compañeros a un proyecto como propietario, administrador, miembro u observador.

  • Inicio de sesión único

    Tu equipo inicia sesión con la cuenta existente de la organización.

  • Importar archivos BCF

    Carga un .bcfzip con todas las incidencias, comentarios y puntos de vista, por ejemplo de una comprobación del modelo.

  • Exportar archivos BCF

    Descarga todas las incidencias de un proyecto como .bcfzip para cualquier programa BCF.

  • BCF API 2.1

    La API estándar abierta para proyectos, incidencias, comentarios y puntos de vista, para conectar con otro software.

  • Claves API por proyecto

    Da a un script o herramienta de control acceso a un solo proyecto, opcionalmente con fecha de caducidad.

  • Guardar en tu Nextcloud

    Guarda las incidencias como .bcfzip en la carpeta del proyecto, junto a los modelos IFC, y vuelve a abrirlas desde allí.

  • Manifiesto del proyecto al día

    Al guardar, el conjunto de incidencias se añade al manifiesto del proyecto, para que otras aplicaciones OpenAEC lo encuentren.

  • En tu propio servidor

    Una instalación Docker con base de datos; los datos del proyecto no salen de tu entorno.

  • Varias organizaciones

    Una instalación puede dar servicio a varias organizaciones, cada una con su propio Nextcloud.

  • Cinta conocida

    La misma cinta que las demás aplicaciones OpenAEC, con atajos para importar (Ctrl+I) y exportar (Ctrl+E).

Preguntas frecuentes

¿Qué archivos puedo abrir?

Archivos BCF (.bcfzip) en la versión 2.1, como los generan Solibri, Navisworks, BIMcollab, Revit y las aplicaciones OpenAEC. BCF 3.0 aún no es compatible. BCF Manager Studio no abre el propio modelo IFC; para eso usa un visor IFC.

¿Tengo que instalar algo?

Sí, en un servidor. BCF Manager Studio es una aplicación de servidor que instalas con Docker en tu propio servidor, junto con PostgreSQL. Después tu equipo trabaja simplemente en el navegador. Aún no hay ninguna versión lista para usar, y la versión de prueba en línea se cerró el 8 de octubre de 2026.

¿Cuánto cuesta?

Nada. El código fuente es público en GitHub y solo pagas tu propio servidor. El código fuente aún no tiene archivo de licencia; llegará con la primera versión.

¿En qué formato se guarda mi trabajo?

Las incidencias se guardan en una base de datos PostgreSQL en tu servidor, con las capturas como imágenes al lado. Puedes exportarlas en cualquier momento como .bcfzip, el estándar abierto de buildingSMART, o guardarlas así en tu Nextcloud.

¿En qué sistemas funciona?

El servidor funciona en Docker, sobre Linux. Tu equipo trabaja en un navegador moderno en Windows, macOS o Linux.

¿Encaja con la práctica de la construcción?

Sí. BCF es el estándar abierto de buildingSMART para la coordinación BIM: una comprobación del modelo genera incidencias, que comentas, asignas y cierras. Los estados, prioridades, fases y etiquetas siguen BCF 2.1, así que se mantienen intactos al intercambiarlos con otras partes.

¿Qué puede hacer un asistente de IA con ello?

Aún no hay servidor MCP. Sin embargo, un asistente o script con una clave API puede leer y crear incidencias, comentarios y puntos de vista de un proyecto a través de la API BCF 2.1.

¿Ya puedo usarlo?

Todavía no tal cual. BCF Manager Studio es un concepto: no hay ninguna versión ni ya una versión de prueba pública, y el desarrollo está parado desde abril de 2026. Si quieres, puedes compilarlo tú mismo a partir del código fuente en GitHub e instalarlo en tu propio servidor.

¿Puedo editar una incidencia en pantalla?

En parte. En pantalla creas incidencias y escribes comentarios. El estado, la asignación y la fecha límite de una incidencia existente todavía no se cambian en pantalla, sino mediante una importación BCF o la API. La búsqueda en la lista de incidencias también está por llegar.

¿Funciona con Revit?

A través de archivos BCF, sí: simplemente cargas un .bcfzip de Revit. También hay una versión de prueba aparte de un complemento para Revit 2025 que abre archivos .bcfzip en Revit. Una conexión directa entre ese complemento y BCF Manager Studio todavía no funciona.

Tecnología

Para quien quiera saber cómo está hecho.

Rust · Axum

Servidor rápido y ligero en Rust con Axum y Tokio.

React · TypeScript

Interfaz web con Vite y Tailwind, con el estilo de la casa de OpenAEC.

BCF 2.1 · BCF API 2.1

Biblioteca Rust propia que lee y escribe .bcfzip, más la API estándar de buildingSMART.

PostgreSQL 16 · Docker

Base de datos con migraciones; todo arranca con Docker Compose detrás de Caddy.

OIDC · JWT · claves API

Inicio de sesión único con Authentik, sesiones JWT y claves por proyecto.

Nextcloud · WebDAV

Almacenamiento en tu propio Nextcloud mediante la biblioteca compartida openaec-cloud, con manifiestos .wefc.
