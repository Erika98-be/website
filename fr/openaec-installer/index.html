OpenAEC Installer

Installez, mettez à jour et lancez toutes les applications OpenAEC depuis une seule application

01 Mises à jour

Toujours la dernière version, sans chercher

Chaque carte indique la version installée et celle qui est disponible. Un clic met à jour une application, ou toutes à la fois. L'Installer attend que vous ayez fermé l'application, pour que vous ne perdiez rien, puis la relance.

Questions fréquentes

Dois-je installer quelque chose ?

Oui, l'Installer lui-même : une petite application de bureau d'environ 5 Mo sous Windows. Ensuite, vous installez les autres applications depuis l'Installer. Les outils web ne demandent rien.

Combien coûte l'OpenAEC Installer ?

Rien. L'Installer est gratuit et open source sous licence CC BY-SA 4.0, sans compte ni abonnement. Les applications qu'il installe sont gratuites aussi.

Sur quels systèmes fonctionne-t-il ?

Windows, macOS (Intel et Apple Silicon) et Linux (.deb, AppImage et Snap). Installer, mettre à jour et lancer des applications fonctionne sous Windows et Linux. Sous macOS, le catalogue et les outils web fonctionnent ; l'installation d'applications n'y est pas encore possible.

Quelles applications puis-je installer avec ?

Quatorze applications de bureau, dont Open PDF Studio, Open Planner Studio, Open Calc Studio, Open Geotechniek Studio, Open Pointcloud Studio et Monty IFC Viewer, et cinq outils web comme Open Energy Studio et OpenBooks. Quand une application s'ajoute, elle apparaît dans le catalogue après une mise à jour de l'Installer.

D'où viennent les téléchargements ?

Toujours des versions officielles de l'application sur GitHub. Si une application fournit une signature numérique, l'Installer la vérifie pendant le téléchargement et ne lance rien si elle manque ou est incorrecte.

Est-ce que je perds mon travail quand une application est mise à jour ?

Non. Si l'application est ouverte, l'Installer vous demande de la fermer et attend ; il ne la ferme jamais lui-même. Après la mise à jour, l'application redémarre.

Ai-je besoin de droits d'administrateur ?

Généralement non. L'Installer s'installe par utilisateur, et sous Linux les applications vont dans votre propre dossier. Seule une application installée pour tout l'ordinateur demande des droits d'administrateur lors de la mise à jour.

Technologie

Pour ceux qui veulent savoir comment c'est construit.

Tauri 2 · Rust

Une petite application native pour Windows, macOS et Linux ; Rust gère les téléchargements, les vérifications et l'installation.

React · TypeScript

L'interface, construite avec le paquet web du design OpenAEC 0.4 : jetons, polices et icônes.

GitHub Releases

Un seul flux de versions pour toutes les applications, avec l'API GitHub en secours et un cache d'une heure.

Signatures minisign

Un latest.json signé par application, au même format que le Tauri updater, avec un kit de publication pour les applications.

Windows: NSIS · MSI · Inno Setup

Détection via le registre, mises à jour silencieuses dans le même type d'installateur, par utilisateur ou pour tout l'ordinateur.

Linux: AppImage

Un dossier géré dans ~/.local/share avec des entrées de menu selon la norme XDG, sans droits d'administrateur.
