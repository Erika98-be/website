Littérature de construction ancienne

OpenBooks

Des ouvrages techniques que plus personne n'imprime, gratuits dans votre navigateur

Quiconque rénove ou évalue un bâtiment existant veut savoir comment on construisait autrefois. OpenBooks met en ligne des livres de construction numérisés de 1670 aux années soixante : choisissez un livre, feuilletez les pages originales et zoomez sur les dessins.

Les ouvrages de référence introuvables d'occasion

03 Lire

05 Histoire de la construction

Trois siècles de savoir constructif côte à côte

Du traité sur les cinq ordres de colonnes du tailleur de pierre de la ville de Dordrecht, Symon Bosboom, en 1670, aux méthodes de calcul de Vandepitte des années soixante. Utile pour la restauration, et agréable à feuilleter.

Questions fréquentes

Quels livres sont disponibles ?

Le lecteur contient douze livres totalisant plus de 2 300 pages : cinq tomes des Constructies van Gebouwen de Wattjes, l'Architectonische Vormenleer de Gugel, le Berekening van Constructies I de Vandepitte, Staalconstructies de Potma et De Vries, le Handboek Houtconstructies de Zwiers, les prescriptions béton armé de 1950, le Cort onderwys de Bosboom (1670) et un livre sur les portes à panneaux. GitHub contient encore plus de numérisations, comme les autres tomes de Wattjes et Vandepitte, le Vademecum de Bernoulli et les prescriptions béton de 1974.

Dois-je installer quelque chose ?

Non. Ouvrez open-books.open-aec.com dans votre navigateur et choisissez un livre. Aucun compte n'est nécessaire.

Combien ça coûte ?

Rien. OpenBooks est gratuit et open source ; le site et les scripts sont sous licence LGPL-3.0.

Dans quel format sont les numérisations ?

Chaque page est une image distincte (PNG ou JPG) dans un dossier par livre sur GitHub. Vous pouvez les consulter et les télécharger, page par page ou toute la collection.

Sur quels systèmes fonctionne-t-il ?

Dans tout navigateur récent sous Windows, macOS et Linux. Il est plus agréable sur un ordinateur avec souris ; le site lui-même est en néerlandais.

Est-ce adapté à la pratique du bâtiment ?

Oui, pour les travaux sur bâtiments existants : vous voyez comment murs, fondations, menuiseries, escaliers et toitures étaient construits et calculés. Attention : les prescriptions de la collection sont historiques et ne s'appliquent plus aujourd'hui.

Puis-je chercher dans le texte des livres ?

Pas encore. Le champ de recherche porte pour l'instant sur le titre et l'auteur. La reconnaissance de texte (OCR), pour chercher des mots dans les pages et copier du texte, est prévue.

Ces livres peuvent-ils être en ligne ?

Pour autant qu'on puisse le vérifier, les livres sont libres de droits. C'est parfois difficile à établir. Si vous pensez qu'un livre est encore protégé, signalez-le sur GitHub et nous le retirerons.

Puis-je ajouter un livre ?

Volontiers. Numérisez un livre de construction libre de droits et proposez les pages via une contribution sur GitHub, ou ouvrez un ticket pour suggérer un livre.

Technologie

Pour ceux qui veulent savoir comment c'est construit.

React 18

La bibliothèque et le lecteur forment une seule page web en React, sans étape de compilation.

Git

Toutes les numérisations sont dans un dépôt Git, un dossier par livre : chaque modification est traçable.

Site statique

Ni code serveur ni base de données : les pages se chargent directement depuis le dépôt.

GitHub Actions

Un workflow publie automatiquement chaque modification sur open-books.open-aec.com.

Python

De petits scripts numérotent et renomment les pages numérisées de chaque livre.

LGPL-3.0

Licence ouverte pour le code ; les livres eux-mêmes sont, autant qu'on sache, libres de droits.
