BCF Manager Studio

Tous les problèmes BIM d'un projet au même endroit, sur votre propre serveur

BCF Manager Studio est un concept de gestion des problèmes dans les projets BIM. Vous rassemblez par projet les constats des contrôles de maquette, vous en discutez avec votre équipe et vous les transmettez en fichier BCF à tout autre logiciel BIM.

Fonctions

Du constat à la solution, avec toute l'équipe

Commencez par les points forts ou choisissez un thème.

01 Projets

Chaque projet a sa liste de problèmes

Créez par projet un seul endroit pour tous les constats, avec un nom, un lieu, une description et une image du projet. La vue d'ensemble montre d'un coup d'œil de quel bâtiment il s'agit, et plus personne ne cherche dans des e-mails et des tableurs épars.

02 Vue d'ensemble

Voyez dans une seule liste ce qui reste ouvert

Chaque problème figure dans la liste avec son statut, sa priorité et son type, comme conflit, problème ou remarque. Le tableau de bord compte les problèmes ouverts, en cours et clos, et montre par priorité où se trouve le travail.

03 Vue de la maquette

Voyez tout de suite où est le problème

Chaque problème affiche la capture de la maquette, avec la position de la caméra. Le point de vue renvoie aux éléments par leur IFC GlobalId, de sorte qu'une visionneuse BCF va directement à la bonne pièce.

04 Collaboration

Discutez du problème là où il se trouve

Les commentaires sont attachés au problème lui-même, avec la date et l'heure, de sorte que toute la discussion reste réunie. À côté, vous voyez à qui il est attribué, l'échéance, la phase et les étiquettes.

  • Créer des projets

    Avec un nom, un lieu et une description, et une image de projet.

  • Nouveau problème

    Titre, description, type, statut et priorité dans un seul formulaire.

  • Statut et priorité

    Ouvert, actif, clos ou rouvert ; de faible à critique, comme le définit BCF.

  • Tableau de bord par projet

    Le nombre de problèmes ouverts, en cours et clos, et un histogramme par priorité.

  • Filtrer

    N'affichez sur le tableau de bord que les problèmes d'un statut ou d'une priorité donnés.

  • Captures sur chaque problème

    L'image de la maquette s'affiche en grand sur le problème et en petit sur les cartes du tableau de bord.

  • Position de la caméra

    Perspective ou orthographique, avec la position de la caméra enregistrée dans le point de vue.

  • Éléments par IFC GlobalId

    Sélection, visibilité et coloration par élément, pour qu'une visionneuse montre la bonne pièce.

  • Commentaires

    Écrivez un commentaire sur le problème ; chaque commentaire reçoit une date et une heure.

  • Attribution et échéance

    À qui le problème est attribué, l'échéance, la phase et les étiquettes, tels qu'ils viennent du fichier BCF.

  • Membres par projet

    Ajoutez des collègues à un projet comme propriétaire, administrateur, membre ou lecteur.

  • Authentification unique

    Votre équipe se connecte avec le compte existant de l'organisation.

  • Importer des fichiers BCF

    Chargez un .bcfzip avec tous les problèmes, commentaires et points de vue, par exemple issu d'un contrôle de maquette.

  • Exporter des fichiers BCF

    Téléchargez tous les problèmes d'un projet en .bcfzip pour tout logiciel BCF.

  • BCF API 2.1

    L'API standard ouverte pour les projets, problèmes, commentaires et points de vue, pour relier d'autres logiciels.

  • Clés API par projet

    Donnez à un script ou à un outil de contrôle l'accès à un seul projet, avec une date d'expiration si vous le souhaitez.

  • Enregistrer dans votre Nextcloud

    Conservez les problèmes en .bcfzip dans le dossier du projet, à côté des maquettes IFC, et rouvrez-les depuis là.

  • Manifeste du projet à jour

    À l'enregistrement, le lot de problèmes est ajouté au manifeste du projet, pour que d'autres applications OpenAEC le trouvent.

  • Sur votre propre serveur

    Une installation Docker avec base de données ; vos données de projet ne quittent pas votre environnement.

  • Plusieurs organisations

    Une installation peut servir plusieurs organisations, chacune avec son propre Nextcloud.

  • Ruban familier

    Le même ruban que les autres applications OpenAEC, avec des raccourcis pour importer (Ctrl+I) et exporter (Ctrl+E).

Questions fréquentes

Quels fichiers puis-je ouvrir ?

Les fichiers BCF (.bcfzip) en version 2.1, tels que les produisent Solibri, Navisworks, BIMcollab, Revit et les applications OpenAEC. BCF 3.0 n'est pas encore pris en charge. BCF Manager Studio n'ouvre pas la maquette IFC elle-même ; utilisez pour cela une visionneuse IFC.

Dois-je installer quelque chose ?

Oui, sur un serveur. BCF Manager Studio est une application serveur que vous installez avec Docker sur votre propre serveur, avec PostgreSQL. Votre équipe travaille ensuite simplement dans le navigateur. Il n'existe pas encore de version prête à l'emploi, et la version d'essai en ligne a été arrêtée le 8 octobre 2026.

Combien ça coûte ?

Rien. Le code source est public sur GitHub et vous ne payez que votre propre serveur. Le code source n'a pas encore de fichier de licence ; il viendra avec la première version.

Dans quel format mon travail est-il enregistré ?

Les problèmes sont stockés dans une base de données PostgreSQL sur votre serveur, et les captures sous forme d'images à côté. Vous pouvez les exporter à tout moment en .bcfzip, le standard ouvert de buildingSMART, ou les enregistrer ainsi dans votre Nextcloud.

Sur quels systèmes fonctionne-t-il ?

Le serveur fonctionne dans Docker, sous Linux. Votre équipe travaille dans un navigateur récent sous Windows, macOS ou Linux.

Est-ce adapté à la pratique du bâtiment ?

Oui. BCF est le standard ouvert de buildingSMART pour la coordination BIM : un contrôle de maquette produit des problèmes que vous discutez, attribuez et clôturez. Les statuts, priorités, phases et étiquettes suivent BCF 2.1, si bien qu'ils restent intacts lorsque vous les échangez avec d'autres intervenants.

Que peut en faire un assistant IA ?

Il n'y a pas encore de serveur MCP. Un assistant ou un script muni d'une clé API peut toutefois lire et créer les problèmes, commentaires et points de vue d'un projet via l'API BCF 2.1.

Puis-je déjà l'utiliser ?

Pas directement. BCF Manager Studio est un concept : il n'y a pas de version publiée ni plus de version d'essai publique, et le développement est à l'arrêt depuis avril 2026. Si vous le souhaitez, vous pouvez le compiler vous-même à partir du code source sur GitHub et l'installer sur votre propre serveur.

Puis-je modifier un problème à l'écran ?

En partie. À l'écran, vous créez des problèmes et écrivez des commentaires. Le statut, l'attribution et l'échéance d'un problème existant ne se modifient pas encore à l'écran, mais bien via un import BCF ou l'API. La recherche dans la liste des problèmes est aussi encore à venir.

Fonctionne-t-il avec Revit ?

Via les fichiers BCF, oui : vous chargez simplement un .bcfzip issu de Revit. Il existe aussi une version de test séparée d'un module pour Revit 2025 qui ouvre les fichiers .bcfzip dans Revit. Une connexion directe entre ce module et BCF Manager Studio ne fonctionne pas encore.

Technologie

Pour ceux qui veulent savoir comment c'est construit.

Rust · Axum

Serveur rapide et sobre en Rust avec Axum et Tokio.

React · TypeScript

Interface web avec Vite et Tailwind, dans le style maison d'OpenAEC.

BCF 2.1 · BCF API 2.1

Bibliothèque Rust maison qui lit et écrit les .bcfzip, plus l'API standard de buildingSMART.

PostgreSQL 16 · Docker

Base de données avec migrations ; tout démarre avec Docker Compose derrière Caddy.

OIDC · JWT · clés API

Authentification unique via Authentik, sessions JWT et clés par projet.

Nextcloud · WebDAV

Stockage dans votre propre Nextcloud via la bibliothèque partagée openaec-cloud, avec des manifestes .wefc.
