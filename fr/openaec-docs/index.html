OpenAEC Docs

Dossiers de projet, maquettes et manifestes clairement réunis, sur votre propre serveur

OpenAEC Docs est un concept de gestion documentaire pour les projets de construction. Il ajoute une vue d'ensemble des projets, des dossiers fixes et des manifestes aux fichiers déjà présents dans votre Nextcloud.

Ce que fait OpenAEC Docs aujourd'hui

Commencez par les points forts ou choisissez un thème.

01 Projets

Tous vos projets dans une seule vue

Chaque projet apparaît sous forme de carte avec une courte description, son statut et le dossier Nextcloud qui contient les fichiers. Projets actifs, dossiers archivés et modèles se distinguent au premier coup d'œil. Un clic et vous êtes dans le projet.

02 Dossiers fixes

La même organisation reconnaissable dans chaque projet

La barre latérale affiche les dossiers fixes du projet, comme les maquettes, les plans, les calculs et les rapports, avec des noms lisibles. Chacun trouve tout de suite le bon endroit dans chaque projet, même les nouveaux venus.

03 Fichiers

Vos fichiers restent là où ils sont déjà

OpenAEC Docs lit les fichiers directement dans votre Nextcloud. Vous parcourez maquettes, plans et sous-dossiers, voyez la taille de chaque fichier et revenez en arrière par le fil d'Ariane. Aucun second stockage ni copie.

04 Manifestes

Consigner ce qui va ensemble

Un manifeste dans le dossier du projet indique quelles maquettes, quels lots d'observations et quels rapports appartiennent au projet, chacun avec une clé fixe. OpenAEC Docs en affiche clairement le contenu et d'autres outils peuvent y ajouter des éléments via l'API.

  • Vue des projets

    Tous les projets de votre organisation sous forme de cartes, avec description et dossier.

  • Actif, archivé ou modèle

    Chaque projet a un statut, pour ne pas mélanger travaux en cours, dossiers clos et modèles.

  • Créer et archiver des projets

    Un projet est lié à un dossier Nextcloud. Création, modification et archivage passent pour l'instant par l'API, pas encore par l'écran.

  • Dossiers de projet fixes

    Une organisation fixe par projet dans la barre latérale, comme maquettes, plans et rapports, dans un ordre défini.

  • Navigation avec fil d'Ariane

    Parcourez dossiers et sous-dossiers, dossiers en premier, avec la taille de chaque fichier et un clic pour revenir.

  • Directement depuis Nextcloud

    Les fichiers restent dans Nextcloud. OpenAEC Docs ne conserve que les données du projet et l'organisation des dossiers.

  • Réglages par dossier

    Pour chaque dossier, vous définissez un nom, un ordre, une icône, la lecture seule et les types de fichiers attendus.

  • Proposer une organisation

    OpenAEC Docs propose les dossiers fixes à partir des dossiers existants : 01_Modellen devient Modellen.

  • Envoyer, supprimer, créer des dossiers

    Récupérer, envoyer et supprimer des fichiers et créer des dossiers dans le dossier du projet, via l'API pour l'instant.

  • Consulter les manifestes

    L'en-tête et les éléments d'un manifeste clairement affichés : type, nom, chemin et clé.

  • Plusieurs manifestes par projet

    Par exemple un pour les maquettes et un pour les rapports, chacun ouvert directement depuis la barre latérale.

  • Ajouter des éléments

    D'autres outils ajoutent ou mettent à jour un élément d'un manifeste via l'API, selon sa clé fixe.

  • Connecter vos propres outils

    Projets, dossiers, fichiers et manifestes sont tous accessibles par une seule API.

  • Sur votre propre serveur

    Fonctionne dans Docker sur un serveur que vous gérez vous-même. Vos données de projet ne partent pas vers un cloud externe.

  • Authentification unique

    Connexion via le serveur d'authentification de votre organisation, sans mot de passe distinct pour OpenAEC Docs.

  • Plusieurs organisations

    Une installation pour plusieurs organisations, chacune avec son Nextcloud et un accès limité à ses propres projets.

Nouveau en avril 2026

Manifestes : ce qui va avec quoi

La dernière nouvelle fonction date d'avril 2026 : un projet peut avoir plusieurs manifestes, que vous consultez à l'écran. Le développement est à l'arrêt depuis ; il n'y a pas encore de version publiée.

Toutes les modifications

  • Plusieurs manifestes

    Chaque fichier manifeste du dossier du projet apparaît séparément dans la barre latérale.

  • Manifeste à l'écran

    L'en-tête et les éléments d'un manifeste, avec type, nom, chemin et clé.

  • Ajouter via l'API

    D'autres outils ajoutent ou mettent à jour des éléments ; si le manifeste n'existe pas encore, il est créé.

  • Même format que les autres outils

    Le manifeste utilise la bibliothèque partagée des outils cloud d'OpenAEC, pour qu'ils puissent aussi le lire.

Questions fréquentes

Quels fichiers puis-je ouvrir ?

OpenAEC Docs affiche tous les fichiers du dossier du projet dans Nextcloud, des maquettes IFC aux plans PDF et DWG, avec nom et taille. Les manifestes (.wefc) se lisent à l'écran. Ouvrir un fichier ou afficher un aperçu n'est pas encore possible à l'écran ; l'API permet de récupérer n'importe quel fichier.

Dois-je installer quelque chose ?

Oui. OpenAEC Docs est une application serveur à déployer dans Docker sur votre propre serveur, avec PostgreSQL, un Nextcloud pour les fichiers et un serveur d'authentification. Les utilisateurs travaillent ensuite dans le navigateur. Il n'existe pas encore de version prête à l'emploi ni de version d'essai publique.

Combien ça coûte ?

Rien. OpenAEC Docs est open source sous licence MIT. Vous ne payez que votre propre serveur.

Dans quel format mon travail est-il enregistré ?

Vos fichiers restent inchangés dans Nextcloud. Les données du projet et l'organisation des dossiers sont dans une base PostgreSQL, et les manifestes sont des fichiers .wefc (JSON) dans le dossier du projet.

Sur quels systèmes fonctionne-t-il ?

Le serveur fonctionne dans Docker, sous Linux. Les utilisateurs travaillent dans un navigateur récent sous Windows, macOS ou Linux.

Est-ce adapté à la pratique du bâtiment ?

Il suit la pratique courante : une arborescence fixe par projet, des maquettes IFC par discipline et des manifestes qui regroupent maquettes, lots d'observations (BCF) et rapports. Les liens avec le BIM Validator et la plateforme BCF sont prévus mais ne fonctionnent pas encore.

Que peut en faire un assistant IA ?

Il n'y a pas encore de serveur MCP. Un assistant ou un script peut toutefois utiliser l'API REST pour lire projets, dossiers, fichiers et manifestes et ajouter des éléments à un manifeste.

Puis-je déjà l'utiliser ?

Pas encore pour un usage réel. OpenAEC Docs est un concept : la base est là, mais il n'y a ni version publiée, ni installation publique, ni nouveau développement depuis avril 2026. Pour aider, consultez le code source sur GitHub.

Puis-je envoyer des fichiers et créer des dossiers à l'écran ?

Pas encore. Les boutons d'envoi, de nouveau dossier, de recherche et de statut des documents figurent déjà dans le ruban mais ne font encore rien. L'envoi, la suppression et la création de dossiers fonctionnent via l'API.

Ai-je besoin de Nextcloud ?

Oui. OpenAEC Docs n'a pas de stockage propre ; il travaille avec les fichiers du Nextcloud de votre organisation. Pour chaque organisation, vous indiquez quel Nextcloud lui correspond.

Technologie

Pour ceux qui veulent savoir comment c'est construit.

Rust · Axum

Un serveur rapide et compact en Rust avec Axum, qui relaie toutes les requêtes vers Nextcloud.

React · TypeScript

L'interface web en React 19 et TypeScript, construite avec Vite et mise en forme avec Tailwind dans le style OpenAEC.

Nextcloud · WebDAV

Les fichiers résident dans Nextcloud et sont lus et écrits via WebDAV ; OpenAEC Docs ne stocke aucun fichier.

PostgreSQL 16

Projets, organisation des dossiers, utilisateurs et rôles dans PostgreSQL, avec SQLx et des migrations numérotées.

OIDC · JWT

Connexion via OpenID Connect avec PKCE (par exemple Authentik) et un jeton de session valable 24 heures.

Docker

Une seule image avec serveur et interface web, plus des fichiers Docker Compose pour le développement et la production.
