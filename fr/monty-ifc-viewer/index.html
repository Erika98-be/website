Fonctions

Du modèle à l'ordre de montage, lisible par tous

Commencez par les points forts ou choisissez un thème.

01 Séquence de construction

Montrez comment le bâtiment s'élève

Lancez le montage ou avancez phase par phase dans le modèle avec le curseur. Ce qui est déjà posé garde sa couleur, la phase en cours s'allume en orange et ce qui reste à venir est transparent. L'ordre provient du repère (Mark) de chaque élément.

02 Filtrage

Ne voyez que ce dont vous avez besoin

Recherchez un élément par repère, ou cochez des plages de repères et des types d'éléments. Le reste du modèle devient transparent pour voir où se trouvent ces pièces.

03 Coupe

Regardez à l'intérieur du bâtiment

Placez une boîte de coupe autour du modèle et déplacez ses faces avec les flèches. Retirez un étage et voyez l'aménagement et les murs en dessous.

04 Vue éclatée

Écartez le modèle

La vue éclatée écarte tous les éléments, aussi loin que vous le souhaitez. Idéal pour montrer de quelles pièces se compose un projet préfabriqué ou en bois.

05 Sélection

Cliquez sur une pièce et isolez-la

Touchez un élément pour voir son nom et son repère. Isolez-le ou masquez-le d'un bouton, ou sélectionnez-en plusieurs à la fois, aussi d'un geste sur tablette.

  • Lecture pas à pas

    Lecture, pause, phase précédente et suivante, ou accès direct à une phase avec le curseur.

  • À votre rythme

    Choisissez de deux secondes à un quart de seconde par phase.

  • Fait, en cours, à faire

    Pièces posées dans leur couleur, phase en cours en orange, le reste transparent.

  • Ordre issu du repère

    Lit le repère dans les propriétés IFC ou dans Revit, y compris les repères CLT des éléments bois.

  • Boîte de coupe

    Coupez le modèle sur six côtés et déplacez ou faites pivoter la boîte.

  • Vue éclatée

    Écartez les éléments avec un curseur.

  • Mesure

    Distance, distance perpendiculaire et surface, aussi sur tablette.

  • Jour et nuit

    Un affichage clair ou sombre, d'un seul bouton.

  • Zoom et réinitialisation

    Zoomez sur tout le modèle ou réinitialisez coupe, mesures et vue éclatée d'un coup.

  • Cliquer un élément

    Voyez son nom et son repère, et isolez ou masquez l'élément.

  • Plusieurs éléments à la fois

    Avec Ctrl ou Maj, ou avec le bouton de sélection multiple sur tablette.

  • Menu contextuel

    Isoler, masquer et réinitialiser depuis un menu.

  • Filtrer par repère et type

  • Un lien par projet

    Votre client ouvre le modèle sans rien installer ni téléverser.

  • Vue d'ensemble des projets

    Une page d'accueil par client avec aperçu, phase et lieu par projet, recherche et filtre par type.

  • Plusieurs modèles par projet

  • Tablette et téléphone

Questions fréquentes

Quels fichiers puis-je ouvrir ?

Des modèles IFC issus de tout logiciel BIM, comme Revit, Archicad ou Tekla. La version web affiche les modèles stockés sur le serveur Speckle : fichier IFC téléversé ou envoyé directement depuis Revit avec le connecteur Speckle. L'application de bureau ouvre les fichiers IFC de votre ordinateur.

Dois-je installer quelque chose ?

Non. Quiconque reçoit un lien ouvre le modèle directement dans le navigateur, aussi sur tablette ou téléphone. Pour ouvrir vos propres fichiers IFC sans les partager, installez l'application de bureau.

Combien coûte Monty IFC Viewer ?

Rien. La consultation est gratuite et sans compte, et le code source est public sur GitHub.

Sur quels systèmes fonctionne-t-il ?

La version web fonctionne dans tout navigateur moderne, sur ordinateur, tablette et téléphone. L'application de bureau existe pour Windows (.exe et .msi), macOS sur Apple Silicon (.dmg) et Linux (.deb, .rpm et AppImage).

Est-ce adapté à la pratique du bâtiment ?

Oui. Il utilise l'IFC, le standard ouvert du BIM, et tire l'ordre du repère (Mark) que vous renseignez déjà dans Revit ou dans les propriétés IFC. Pour la construction bois, il lit aussi les repères des éléments CLT.

Comment mettre mon propre modèle dans la version web ?

Le modèle est placé sur le serveur Speckle d'OpenAEC, par téléversement IFC ou depuis Revit. Le projet reçoit ensuite son propre lien et une place sur la page projets de votre client. Contactez-nous pour le mettre en place.

Puis-je ouvrir un fichier IFC directement dans la version web ?

Pas encore. La version web affiche les modèles partagés du serveur. Pour un fichier de votre ordinateur, utilisez l'application de bureau.

Puis-je voir toutes les propriétés d'un élément ?

Pas encore pour les modèles IFC dans la version web : le panneau y affiche le nom et le repère. Pour les modèles envoyés directement depuis Revit, vous voyez aussi les paramètres par groupe.

Quelle différence entre la version web et l'application de bureau ?

La version web est conçue pour le partage : un lien, une vue d'ensemble des projets, mesures, coupe et filtres, et elle fonctionne sur tablette. L'application de bureau (version 1.0) ouvre des fichiers IFC de votre ordinateur et colore les éléments selon un paramètre.

Technologie

Pour ceux qui veulent savoir comment c'est construit.

Speckle Viewer

La visionneuse 3D open source de Speckle pour l'affichage, les filtres, les mesures, la coupe et la vue éclatée, utilisée via son API publique.

Serveur Speckle propre

Modèles et versions sont hébergés sur speckle.open-aec.com, avec import IFC et connecteur Revit.

Three.js et WebGL

Une 3D fluide dans le navigateur, sans plug-in.

TypeScript et Vite

Code strict et modulaire sans framework, compilé en site statique.

Conçu pour le tactile

Boutons, sélection et mesures fonctionnent aussi au doigt sur tablette et téléphone.

Bureau avec web-ifc

L'application de bureau lit les fichiers IFC localement avec web-ifc, avec des téléchargements signés.
