Extension pour Open 2D Studio

Drawing Statistics

Sachez en un clic combien de formes contient votre dessin

Une petite extension gratuite pour l'application de bureau Open 2D Studio. Elle ajoute l'onglet Add-Ins avec le bouton Shape Count, qui compte toutes les formes et affiche le total et le nombre par type.

Fonctions

Petite, mais pratique

Commencez par les points forts ou choisissez un thème.

01 Comptage

Un clic donne le total et le nombre par type

Ouvrez l'onglet Add-Ins et cliquez sur Shape Count. Un message indique combien de formes il y a et combien sont des cercles, rectangles, lignes, cotes ou textes. Pratique pour voir vite ce que contient un dessin.

En savoir plus

02 Commande

Aussi une commande pour les scripts et le terminal IA

L'extension ajoute la commande stats show à la liste des commandes d'Open 2D Studio. Tapez commands dans le terminal pour la voir. Elle renvoie le même comptage sous forme de texte.

En savoir plus

03 Installation

Installer avec un zip, désactiver en un clic

Téléchargez le zip et, dans Open 2D Studio, choisissez File, Extensions, Install from file. L'extension apparaît ensuite sous Installed, où vous pouvez la désactiver ou la supprimer.

En savoir plus

04 Votre extension

Un exemple pour créer votre propre extension

Deux fichiers et une centaine de lignes de JavaScript montrent comment une extension ajoute un onglet, un bouton et une commande. Copiez-le, adaptez-le et vous avez votre propre outil dans Open 2D Studio.

Questions fréquentes

Quels fichiers puis-je ouvrir ?

L'extension n'ouvre pas de fichiers elle-même. Elle compte ce qui est ouvert dans Open 2D Studio, y compris un dessin importé depuis un DXF.

Dois-je installer quelque chose ?

Oui : l'application de bureau Open 2D Studio (v0.15 ou plus récente) et cette extension. Récupérez drawing-statistics-1.0.1.zip dans la version 1.0.1 sur GitHub et choisissez dans Open 2D Studio File, Extensions, Install from file. La version web d'Open 2D Studio ne peut pas encore installer d'extensions.

Combien ça coûte ?

Rien. Le code source est public sur GitHub. Il n'y a pas encore de fichier de licence ; pour réutiliser le code, demandez-le dans le dépôt.

Dans quel format mon travail est-il enregistré ?

L'extension n'enregistre rien et ne modifie pas votre dessin. Le comptage s'affiche dans un message ; vous enregistrez votre dessin dans Open 2D Studio comme d'habitude.

Sur quels systèmes fonctionne-t-elle ?

Partout où fonctionne l'application de bureau Open 2D Studio : Windows, macOS et Linux. Pas dans la version web.

Que peut en faire un assistant IA ?

La commande stats show figure dans la liste des commandes d'Open 2D Studio. Le terminal IA de l'application de bureau reçoit cette liste et peut donc demander le comptage.

Compte-t-elle seulement le dessin affiché ?

Non. Elle compte toutes les formes du fichier ouvert, y compris celles d'autres dessins et les formes masquées. Compter par dessin, par calque ou seulement la sélection n'est pas encore possible.

Puis-je enregistrer ou exporter le comptage ?

Pas encore. Le comptage n'apparaît que dans un message, avec les noms anglais des types de formes.

Puis-je m'en servir pour créer ma propre extension ?

C'est son but. Une extension est un dossier avec manifest.json et un fichier JavaScript contenant une fonction onLoad, où vous ajoutez onglets, boutons et commandes. Voyez main.js pour l'exemple.

Technologie

Pour ceux qui veulent savoir comment c'est construit.

JavaScript

Un seul main.js en module CommonJS (module.exports), sans dépendances ni compilation.

manifest.json

id, version, minAppVersion 0.15.0, catégorie Utility et les droits commands, ribbon et events.

Extension API

onLoad(api) avec api.ui.addRibbonTab, api.ui.addRibbonButton, api.commands.register et api.entities.list.

Command registry

Enregistre stats/show dans le registre de commandes d'Open 2D Studio ; comme outil, il s'appelle cad_stats_show.

Zip

La version est un zip avec manifest.json et main.js, qu'Open 2D Studio décompresse dans son dossier d'extensions.

Open 2D Studio

L'application de bureau (Tauri) charge l'extension au démarrage et retire onglet, bouton et commande à la désactivation.
